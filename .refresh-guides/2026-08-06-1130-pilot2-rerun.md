## 검수 페이지 다시 만들기

지금 올라가 있는 판: https://claude.ai/code/artifact/e236aa40-f1db-4fa8-adca-385c886bbcc9
(파일 `<scratchpad>/pilot2-review.html`, 같은 경로로 다시 Artifact 호출하면 같은 주소에 덮인다)

데이터 재조립 — `pa`/`pb`는 **요청 전문**이라 `.req.json`에서 읽는다:

```python
import json,glob,sys,os
sys.path.insert(0,'translate')
import batch_pages as B
CH={json.loads(l)['cid']:json.loads(l) for l in open('translate/batch/pilot-chunks.jsonl',encoding='utf-8')}
def load(d):
    o={}
    for f in glob.glob(f'translate/batch/{d}/*.jsonl'):
        for l in open(f,encoding='utf-8'):
            r=json.loads(l); o[r['id']]=r
    return o
A,Bf=load('page-out-pilot'),load('page-out-pilot-fresh')
def req(d,cid):
    f=f'translate/batch/{d}/{cid}.req.json'
    if not os.path.exists(f): return None
    r=json.load(open(f,encoding='utf-8'))
    return r["system"]+"\n\n──── 사용자 메시지 ────\n"+json.dumps(r["user"],ensure_ascii=False,indent=1)
scenes=[{"cid":cid,"map":c["map"],"name":c["map_name"],"event":c["event_name"],
         "cast":[x["name"] for x in c["cast"]],"route":B.route(c),
         "pa":req('page-out-pilot',cid),"pb":req('page-out-pilot-fresh',cid),
         "rows":[{"id":r["id"],"who":r["who"],"es":r["es"],"ko":r["ko"],"ok":r.get("approved",False),
                  "a":(A.get(r["id"]) or {}).get("new"),"aw":(A.get(r["id"]) or {}).get("why"),
                  "b":(Bf.get(r["id"]) or {}).get("new"),"bw":(Bf.get(r["id"]) or {}).get("why")}
                 for r in c["rows"]]}
        for cid,c in sorted(CH.items(),key=lambda x:x[1]['map'])]
```
그 뒤 HTML의 `const DATA = [...];\nconst V` 자리를 `re.sub`으로 갈아 끼우고 다시 Artifact.
페이지 기능: 문장 눌러 고르기 · 직접(고쳐 쓰기) · 보류 · 메모(선택 무관) · 문맥(장면 흐름) ·
프롬프트 전문(A/B 탭). 결과 표 다섯 칸 — `id / 고른것 / 화자 / 문장 / 메모`.

## 판정을 정본에 반영하는 법 (1차 때 쓴 흐름)

1. 받은 표를 TSV로 저장.
2. `고른것`이 현행/보류거나 「직접」인데 문장이 촌평이면 건너뛴다. **1차 때 24건 중 11건이
   문장이 아니라 나에게 남긴 물음이었다** — 눈으로 갈라야 한다.
3. id → (맵, 접힌 원문)으로 정본 열쇠를 만들고 `translate/ko/00-maps.jsonl`을 고친다.
4. `validate.check(현행, 새것, 0)`으로 마크업·길이·개행을 확인하고, 앞머리·이탤릭이
   빠진 것은 현행 것을 도로 붙여 수선한다(1차 때 21행).
5. `uv run translate/build.py && uv run translate/verify.py --strict` → FAIL 0 WARN 0.
6. 커밋 꼬리표 `Edit-Source: human`.
7. **고른 줄을 승인 줄에 합친다** — `docs/research/approved-lines.jsonl`에
   `{"map","es","ko","who","src"}`로 덧붙인다. 그게 다음 판 본보기의 원천이 된다.

## 이번 세션에서 헛디딘 것

- **말투를 형용사로 설명하다 세 판을 오갔다.** 「과하다」→평평, 「기본 결이다」→하게체까지.
  승인본 실측(평범한 반말 262 : 문어투 63)이 답이었고, 지금은 본보기로 준다.
- **금지 예시가 그대로 새어 나왔다** — 「나의 벗이여를 지어 붙이지 마라」→「친구여」 산출.
- **프롬프트에 낡은 규칙을 남겨 뒀다** — 앞머리를 안 보내는데 「앞머리는 그대로 두라」가
  남아 있어 모델이 서른 줄에 화자 표기를 지어 붙였다.
- **`names.py rename`이 번역 칸만 보고 바꿔** 「무사히」·「갑주무사」까지 44행 갈아엎었다.
- **v5.2를 물어보지 않고 공개했다** — 초안으로 내리고 태그를 지웠다. 릴리스는 물어보고.
