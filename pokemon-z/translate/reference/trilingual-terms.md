# 포켓몬 스페인어-영어-한국어 공식 명칭 사전 — 조사 요약

산출물: `trilingual-terms.jsonl` (한 줄 한 항목, `{es, en, ko, category, source, confidence, note?}`)

2026-08-02 기준 총 311개 항목. 1차는 여러 세션 담당이 병렬로 웹 위키(Bulbapedia
"In other languages" 표·WikiDex 개별 문서·나무위키)를 하나씩 직접 대조해 채웠고,
2차로 **GitHub 구조화 원천**(PokeAPI 원본 CSV, pret 디컴파일 팬번역 소스코드)을
기계 대조해 재검증·확장했다. 웹 위키 조회는 이제 보조 수단이다.

## 2차 재검증·확장(GitHub 원천) 요약

- **PokeAPI/pokeapi** `data/v2/csv/*.csv`를 raw.githubusercontent.com에서 직접 받아
  파이썬으로 조인·대조했다. 언어 id는 실물 확인 완료(ko=3, es=7, en=9,
  `languages.csv` 1~15행).
- **성격(nature) 25종 전수 대조**: 20건은 우리 값과 PokeAPI CSV가 완전히 일치.
  **5건(Relaxed·Lax·Mild·Quiet·Quirky)에서 스페인어 표기가 갈렸는데, 오류가 아니라
  스페인(유럽) 표기와 중남미 표기가 서로 다른 것이었다** — Bulbapedia Nature 문서로
  재대조해 확인. 기존 값(스페인판)에 중남미판을 병기하도록 갱신했다.
- **알그룹 15종 전수 대조**: 12건 완전 일치, Water 1/2/3의 띄어쓰기(수중1 vs 수중 1)와
  Undiscovered(미발견 vs 알미발견)에서 차이가 났는데, 나무위키·리브레위키 원문 재확인
  결과 **PokeAPI CSV 쪽이 서식 잡음이었다** — 기존 값을 그대로 유지하고 근거를 보강했다.
- **능력치(stat) 8종 전수 대조**: 완전 일치(표현 상세도만 다름, 오류 없음).
- **칼로스 지명 대확장**: `locations.csv`(location_id→region_id)와 `location_names.csv`를
  조인해 칼로스 지역(region_id=6) 소속 위치 106개를 뽑았다. 기존 19개와 겹치는
  항목은 **불일치 0건**으로 완전히 교차검증됐고, **85개(도로 22개·게이트 9개·
  가도/샛길·던전·시설 등)를 새로 추가**했다.
- **게임 버전명 48개 추가**: `version_names.csv`에서 en/es/ko가 전부 채워진 버전만
  뽑아 system 카테고리에 넣었다(레드~레전드 Z-A까지).
- **배틀 로그 문구 재조사**: GitHub에서 `SomeRandomSponge/pokefireredlatino`(pret
  pokefirered 디컴파일의 라틴아메리카 스페인어 팬번역, `src/battle_message.c`)를
  찾아 **실제 게임에 컴파일되는 문자열 상수**를 확인했다. 상성 문구 둘("효과가
  굉장했다!"·"효과가 별로인 듯하다...")은 이 소스 + 한국어 위키백과 인용으로
  verified로 승격했고, 무효 문구("효과가 없는 것 같다...")를 새로 추가했다.
  능력치 랭크 변화 문구 3건은 **스페인어 쪽만** pret 소스로 근거가 강해졌고
  (조합형 문자열 `"{스탯} de {포켓몬} {상승/하강}!"` 확인), 한국어 쪽 권위 있는
  원문 대조는 여전히 못 해서 **confidence는 unverified로 남겨 뒀다** — 한쪽만
  올라간 상태임을 note에 명시.

## 카테고리별 소감

**place(지명)** — Bulbapedia 개별 문서 하단의 "In other languages" 표가 가장 신뢰도 높은
단일 출처였다. 칼로스 도시·마을 16곳, 유명 시설 3곳(프리즘타워·포켓몬리그·챔피언로드),
지방 이름 9곳(관동·성도·호연·신오·하나·알로라·가라르·팔데아·칼로스)을 전부 대조했다.
Kanto/Sinnoh/Alola 세 지방은 팀리드 요청으로 WikiDex(스페인어, 번역 없이 원어 그대로임을
재확인)와 한국어 위키백과 문서 제목(관동지방·신오지방·알로라지방)으로 2차 대조까지
마쳤다.

**person(인물)** — 챔피언·체육관 관장 8명·라이벌 5명·프로페서·팀 플레어 두목·사천왕
4명·다른 세대 유명 인물(레드·그린·실버·오박사·시로나·목호·아이리스·체렌·벨·N·단델·
호브·마리·윤진·성호 등)까지 36개 전부 verified로 마감됐다. 이 카테고리에서 **실제
오류 넷을 잡았다**:
- 발레리(칼로스 페어리 관장)의 한국어명이 "발레리"로 적혀 있었는데, 인용된 나무위키
  URL은 실제로 소드실드 포플러 문서를 가리키고 있었다 — 마슈로 정정.
- 올림피아(칼로스 에스퍼 관장)가 "초련"으로 적혀 있었는데, 초련은 관동지방
  사브리나의 한국어명이다 — 고지카로 정정.
- 라모스(칼로스 풀 관장)는 "한국어 못 찾음(unverified)"으로 남아 있었는데 검색
  한 번으로 바로 나왔다 — 후쿠지로 확인.
- **월리스(호연 챔피언)의 한국어명이 "왈라스"로 적혀 있었는데 이건 영어 이름을
  그대로 음차 추정한 값이었다.** WikiDex의 스페인어명 문서(Plubio)에 실린
  참고 정보와 나무위키 표제어로 대조한 결과 실제 정식 명칭은 **윤진**이다.
  왈라스라는 표기는 어느 자료에서도 나오지 않았다.

시볼드(즈미)·위크스트롬(간피)·스티븐 스톤(성호, 스페인 Máximo Peñas/중남미 Steven
Stone)은 처음엔 검색 스니펫 인용에만 의존해 unverified였으나, Bulbapedia langtable과
WikiDex 원문을 직접 열어 verified로 올렸다.

**battle(배틀 용어)** — 상태이상 6종·능력치 8종(HP·공격·방어·특공·특방·스피드·명중·
회피)·날씨 4종·필드 4종·급소는 Bulbapedia langtable로 확인됐다(verified). 반면 **랭크
변화 문구와 "효과가 굉장했다" 류의 배틀 로그 문장**은 공식 게임 텍스트 원문 덤프를 못
구해서 블로그·커뮤니티 Q&A 인용에 의존했다 — unverified 6건이 여기 몰려 있다. 팀리드
판단으로 이 잔여는 우리 자체 표현집이 정본 역할을 하므로 재확인 대상에서 뺐다. 스페인어판·
한국어판 게임을 직접 켜서 대조하거나 데이터마이닝 텍스트 덤프를 구해야 verified로
올라간다.

**system(시스템 용어)** — 성격 25종·알그룹 15종·리본·PC/박스·노력치·개체값·기술머신
등 64개 전부 verified다. 콘테스트 리본의 한국어 표기("콘테스트 리본")도 커뮤니티
용례로 재확인해 마감했다.

**type(타입)** — 18종 전부 verified. 공식 위키 세 곳이 일치하는 표가 있어 가장
안정적이었다.

## 확정도 태그 기준

- **verified**: 최소 한 출처(WikiDex·Bulbapedia langtable·나무위키 등)를 실제로 열어
  스페인어·한국어 대응을 직접 확인.
- **unverified**: 검색 스니펫 인용에만 의존했거나, 하나의 언어만 확인되고 다른 언어는
  못 미더운 경우. jsonl의 `note`에 이유를 남겨 뒀다.

## 출처별 신뢰 소감 — Bulbapedia/WikiDex "요약" 오검출 사례

이번 조사에서 가장 조심해야 했던 함정은 **원문이 틀린 게 아니라, WebFetch가 페이지를
요약하는 과정에서 오검출을 낸 것**이었다.

- 페이지가 길면 "In other languages" 표 앞에서 요약이 잘려 버리는 경우가 반복됐다
  (Victory Road, Kanto/Unova 지방 문서, Serena, Calem, Diantha 등). 이때는 WikiDex
  개별 언어판이나 나무위키 검색으로 우회했다.
- 코르니(Korrina)의 한국어명을 물었더니 "코르니(일본어와 동일)"라는 말이 안 되는
  답이 나온 적이 있다 — 표를 잘못 읽은 것이었고, 원문을 다시 열어 정정했다.
- **가장 심각했던 것은 person 카테고리의 발레리·올림피아·월리스 오염이다.** 이름이
  비슷하거나 흔한 캐릭터(포플러/발레리, 사브리나/올림피아, 영어 이름 그대로 음차한
  왈라스/윤진)와 뒤섞이는 패턴이 세 번 반복됐다. **이 사전을 번역 검수에 쓸 때 이
  패턴을 기억해 둘 것** — 특히 person 카테고리는 검증 없이 그대로 믿지 말고, 이름이
  같은 타 지방·타 세대 캐릭터가 있는지 한 번 더 의심하는 습관이 필요하다.
