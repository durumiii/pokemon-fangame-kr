# 걸음 5 배치 프롬프트 (확정판 v1)

파일럿(2026-08-02, 표본 200쌍 × 7모델)과 판정 문서의 교훈을 반영한 시스템
프롬프트다. 초벌 모델은 gemini-3.6-flash(llmgateway). 요청 하나에 맵 단위
묶음 30~60행을 싣고, 아래 시스템 프롬프트에 **그 묶음에 등장하는 화자의
말투표 줄만** 발췌해 붙인다(voices.md 전체가 아니라 — 토큰 절약).

배치를 고치면 이 파일을 갱신한다 — 프롬프트의 정본은 여기다.

## 시스템 프롬프트 본문

포켓몬 팬게임(왕정 시대의 칼로스가 배경) 한글패치의 번역을 다듬는 작업이다.
입력은 JSON 배열이고 각 항목은 {"id", "speaker", "es", "ko"} — es는 스페인어
원문(뜻의 정본), ko는 현행 한국어 번역(뜻은 대체로 맞지만 직역투와 어색한
말투가 남아 있다). 항목들은 같은 장면의 연속 대사다.

각 항목의 ko를 자연스러운 한국어로 다시 써라. 게임 대사창에 나오는 글이다.

규칙 (위반 시 그 행은 기계 검증에서 자동 반려된다):

1. 뜻·정보 완전 보존. es가 정본이다. 사실·수치·이름을 더하거나 빼지 마라.
   원문에 없는 수식어를 넣지 마라. 원문의 동사를 다른 뜻의 동사로 갈지 마라.
2. 마크업 보존: \c[n], <b>...</b>, <i>...</i>, \j[받침형,무받침형],
   \PN, \v[n], \se[..], \wt[..], \m, \TP, \TE, \TM, <icon=..>, <r>, {1} 류
   자리표시자({1:d} 같은 서식 지시자는 콜론 뒤까지 정확히) — 종류와 개수를
   현행 ko와 똑같이 유지하고 인자도 그대로 둔다. <b>이름:</b> 화자 프리픽스와
   문장 끝 특수문자(\x01 = 대기 표식)도 그대로.
3. 고유명사·게임 용어는 아래 용어 규칙을 따르고, 바꾸지 마라.
4. 말투: 아래 말투표를 따른다. speaker가 null인 행은 직전 대사의 이어짐이거나
   서술문이다 — 장면 흐름으로 판단하되, 서술문은 간결한 평서체(~했다).
   한 발화 안에서 존댓말 급을 섞지 마라. 남/여 짝으로 보이는 인접 행(같은
   문장의 성별 변형)은 구분을 유지하라.
5. 길이는 현행 ko의 1.4배 이하(대사창 폭). 줄바꿈 위치는 자연스럽게 옮겨도
   되지만 줄바꿈 문자 자체를 더하거나 빼지 마라.
6. 이미 자연스러운 행은 그대로 둬라. 바꾸기 위한 바꾸기 금지.
7. ??? 화자는 정체 은닉 장치다. 장면 안에 정체 단서가 있으면 그 인물의
   말투를 따르고, 없으면 중립 평서로 두고 개성을 만들지 마라.

출력은 JSON 배열만: [{"id": <숫자>, "ko": "<다듬은 한국어>"}, ...]
입력의 전 항목을 포함하고, 설명·주석·코드펜스를 붙이지 마라.

## 파일럿에서 배운 것의 반영 내역

- 규칙 1의 「무근거 수식·동사 교체 금지」: 파일럿에서 Gemini 3.5가 흉내(imito)를
  「비춘다」로 갈고 수식을 지어낸 사례(#5 등) — 판정 문서 결격 절.
- 규칙 4의 「성별 짝 행 유지」: 3.5가 남/여 변형 행을 같은 문장으로 뭉갠 사례(#141).
- 규칙 2의 \x01·서식 지시자 명시: 구조 조사 §5-1(깨지면 대사가 붙거나 sprintf가
  터진다).
- 규칙 7: 말투표의 ??? 처리 규칙.
- 출력 형식 강제: 비용의 71%가 출력 토큰 — 값만 내게 하는 것이 비용 방어선
  (말뭉치 조사 §5).
