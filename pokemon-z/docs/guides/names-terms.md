# 고유명·용어 규율

**고유명 표기 정본은 `translate/canon/names.jsonl`(원장)이다.** 검사는
`uv run tools/names.py check`(작업 중)와 `verify.py`(재배포 게이트 — 변이 잔존은 FAIL).
표기 변경은 **`tools/names.py rename <원문> <새표기>`**로 정본과 원장을 함께 고친다
(받침이 달라지면 조사 경고). 판정 근거는 `translate/glossary.md`에 적는다.
프롬프트용 용어 정본은 `translate/term-pairs.jsonl`.

- **치환·검사는 원문 칸(`k`/`es`)에 그 이름이 있는 행만 건드린다** — 번역 칸만 보고
  바꾸면 무관한 낱말까지 갈아엎는다(「무사히」→「총사히」류). 건너뛴 행은 목록으로
  보여 주고, 치환 뒤 「원문에 없는데 새 표기가 든 행」이 0인지 센다.
- **이름을 문자열 자동 매칭으로 치환하지 마라** — 철자만 같은 우연 일치가 실재한다.
  치환은 확정 명단으로만.
- **창작 지명처럼 보여도 스페인어 정식명 대조부터** — 본가 도시의 스페인어 정식명이
  그대로 쓰인 자리가 많다(대응표는 glossary.md 지명 절).
- **용어 대조는 canon부터, 전거 서열은 glossary.md 머리.** PokéAPI 한국어는 2020년
  대개명 이전이라 이름 전거로 쓰지 않는다(canon 밖 보조만). PKHeX es는 현행명이라
  게임의 구세대명과 다를 수 있다 — canon/aliases.jsonl로 흡수.
- **용어 통일은 원문 쪽에서 세라** — 원문 반복어를 캐서 한국어 분포를 재면 갈래가
  바로 나온다.
- 스페인어 가짜 친구 실사례: Cinta Focus=Focus **Band**, Banda Focus=Focus **Sash**.
- 표기는 「데미지」, 문구는 현행 세대, 음차는 한국어 어감 우선. 없는 우리말을 지어내지
  않는다 — 기준은 「독자가 이미 쓰는 말인가」.
