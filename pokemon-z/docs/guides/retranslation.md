# 주연 대사 재번역 — `translate/batch_pages.py`

**범위** — LLM 배치 재번역의 사정권, 프롬프트 규약, 산출 선별.
**여는 때** — 대사를 배치로 다시 번역할 때 · 프롬프트나 선별 기준을 고칠 때.
**다루지 않는 것** — 한 자리 손수정([text-pipeline.md](text-pipeline.md)) · 말투 정본
([../ledger/voices.md](../ledger/voices.md)).
**전제** — 화자·말투 개념([events-and-speech.md](events-and-speech.md)).

**유료 실행은 정보 가치부터 적는다** — run·screen_llm을 돌리기 전에 「이 실행이 새로
사는 정보가 무엇인가, 기존 산출·plan 단언 검사로 대체되지 않는가」를 한 줄로 답한다.
run은 이미 있는 페이지 산출을 건너뛰므로 **산출 폴더를 통째로 대피시키지 마라** —
바뀐 행만 다시 묻는 것이 기본이다(2026-08-12: 같은 표본을 세 번 결제한 사고).

**번역 단위는 이벤트 페이지(장면 하나)이고, 요청 단위는 그것을 여러 개 묶은 것이다.**
프롬프트 본문·용어 규칙이 요청마다 실리는 고정비가 잡담처럼 짧은 페이지(중앙 2행)에서
비용의 대부분이라, `run`은 행수 예산 `--pack N`(기본 30)까지 페이지를 묶어 한 요청에
보낸다. 페이지는 쪼개지 않고, 장면은 프롬프트에서 장면 id로 구획되며, 화자 지시는
묶음 안에서 한 번만 실린다. 답은 행 id로 갈라 페이지마다 `<cid>.jsonl`에 나눠 적으므로
하류(선별·apply_verdicts·report)는 묶음을 모른다. 묶음에서 행이 빠진 페이지는 단독
요청으로 강등되고 그 수를 run이 찍는다. **묶음이 클수록 한 요청에 선 화자가 많아진다** —
장면별 말투가 흔들리는 것 같으면 `--pack`을 낮춰 견주고, `--pack 1`이면 페이지당 한
요청(묶음 없음)이다. 실측(2026-08-13, 잡담 파일럿 20페이지 37행, `--fresh`):
단독 20요청 $0.066 → `--pack 30` 2요청 $0.016(76% 절감), 강등 0 · 기계 반려 양쪽 1행 동일.

`plan [--pilot]` · `run [--pilot] [--fresh] [--pack N]` ·
`samples <이름>`(본보기 확인) · `report`. 배치 모델은 gemini-3.6-flash +
**reasoning_effort=low**(페이지 단위 배치의 정본 — 근거는 quality.md 「페이지 배치
effort는 low」; minimal은 옛 맵 단위 배치의 판정이다). **작은 표본으로 파라미터를
판정하지 마라.**

**`--npc`를 붙이면 사정권이 이름표 없는 컷신·대화(Z-4 3갈래)로 바뀐다** — 이름표가
한 줄도 없는 페이지의 스프라이트 귀속 행만 담고, 화자·말투는 페르소나표(sprite 키)가
정본이다. 페르소나표에 없는 스프라이트(포켓몬 번호·연출물)는 행째 빠지며 그 수를
plan이 찍는다. 산출은 `batch/npc[-pilot]-chunks.jsonl`·`batch/npc-out[-pilot]/` —
주연 갈래 파일과 안 겹친다.

## 유료 실행의 표준 장비 — 백엔드·모니터링·로깅 (유지자 판정 2026-08-19)

상비 도구든 즉석 조사 스크립트든, **LLM에 돈을 내는 실행은 전부** 아래를 갖추고 돈다.
즉석이라는 이유로 빼지 마라 — 이 절이 생긴 이유가 즉석 스크립트의 결락이다.

- **백엔드 정본은 `translate/batch.py` 한 곳이다.** openrouter 경로: 모델
  `google/gemini-3.7-flash` · **프로바이더 vertex 고정**(`provider.only`, 해제는
  `Z_PROVIDER=` 빈 값) · **flex 티어 필수**(`Z_TIER`, 실측 단가 in 0.1875 · out
  0.9375 $/M — 기존가의 1/8). 즉석 스크립트도 `from batch import MODEL, URL, key_of,
  or_extras`로 이 설정을 타고, 제 payload에 상수를 다시 적지 않는다.
- **진행 표시**: 처리 행/전체 · 누적 실비용(usage.cost 합산) · **ETA**(경과 시간 ×
  남은 배치 비율)를 배치마다 한 줄로 찍는다(`flush=True`). 몇 분짜리 실행을 침묵
  속에 돌리지 않는다.
- **중간 저장·멱등 재개**: 산출은 요청(배치) 단위 파일로 즉시 쓰고, 재실행은 있는
  파일을 건너뛴다. 끊김·타임아웃이 결제 중복이 되지 않는 구조가 기본값이다
  (2026-08-12 「같은 표본 세 번 결제」의 재발 방지와 같은 원칙).
- **로그**: 요청 시각·배치 id·행 수·비용·오류를 로그 파일에 덧붙인다(상비 도구는
  `batch/log.txt` 관례). 실행이 끝나면 총비용을 보고에 적는다.
- 시작 전 정보 가치 한 줄(맨 위 규칙)과, 규모가 있는 실행이면 **예상 비용**을 먼저
  적는다 — flex 단가와 행당 토큰 어림으로 충분하다.

## 사정권과 갈래

- **같은 (맵,원문)은 한 번만 번역한다** — 정본에 한 줄뿐이라 여러 자리에서 물으면 답이
  갈리고 마지막 것만 남는다. 남길 자리는 가장 큰 페이지(문맥이 많은 쪽).
  **통일 원문(여러 맵 복제·한 판, `data/unified-phrases.jsonl`)은 맵 경계 너머로도 한
  번만** — 자리마다 따로 물으면 통일이 도로 갈라진다(2026-08-12 파일럿 실사고).
  반영은 `apply_verdicts`가 값이 같던 전 자리에 전파하고, 반영 뒤 `unified.py sync
  --write`로 목록을 따라 올린다(관리 규율은 text-pipeline 「정본과 빌드」).
- **갈래는 승인 줄(`translate/data/approved-lines.jsonl`)로 가른다** — 있으면 교정판
  (A: 현행을 함께 줌), 없으면 새 번역(B: 스페인어만 줌).
- 세 층을 구분한다: **보호**(`translate/data/protected.jsonl`)는 사정권에서 아예 뺀다 · **승인 줄**은
  사정권에 남되 자동 채택 금지, 말투 본보기의 원천 · 그 밖은 자유.
- **보호 목록은 `uv run translate/provenance.py build`가 만든다** — 제보 시트와 커밋의
  `Edit-Source:` 꼬리표를 읽어 「사람이 자리를 보고 고친 줄」을 가린다. **배치를 돌리기
  전에 다시 만든다** — 낡은 목록으로 돌면 사람이 판정한 자리를 모델이 덮어쓴다.
- 유지자 판정 반영 커밋에는 `Edit-Source: human` 꼬리표. 고른 줄은 승인 줄에 합친다
  (`{"map","es","ko","who","src"}`). 그 꼬리표의 소비자가 위의 `provenance.py`다.

## 마크업은 전부 기계 몫

서식 태그(`<b>`·`<i>`·줄 안 `\c[n]`)와 줄머리 화자 표기는 떼고 민글만 보낸 뒤 원문 쪽
표시 순서대로 되입힌다(`unmark`/`remark`/`split_head`). 되입히는 열쇠는 그 줄 자신의
현행 번역이고, 못 찾으면 원문 그대로 남은 삽입구도 찾아본다. **모델에게 태그를 시키지
마라** — 뜻이 없는 자리라 빠뜨리거나 없던 곳에 지어 붙인다. 모델이 화자 표기를 흉내
내면 그 화자의 이름일 때만 기계가 뗀다(`strip_fake_head`).

## 프롬프트 정본 규약

말투는 `translate/stage0/voices.yaml`, 용어는 `translate/stage0/terms.yaml`, 본문은
`translate/prompt-pages.md` — 셋 다 **직접 편집하는 정본**이다(2026-08-18 강등으로 옛
voice-prompts.jsonl·term-pairs.jsonl은 은퇴했다. gen이 다시 쓰지 않으므로 재생성 없이
바로 반영된다). **md 대장(voices.md·glossary.md)에서 표를 파싱해 프롬프트에 넣지
않는다** — 대장은 근거가 붙는 사람용이다. 새 판정은 stage0 정본과 대장 두 곳에.
무슈 3쌍은 prompt-pages.md에도 자구로 실려 있어 표기가 바뀌면 md 규칙 M도 함께
고친다(어기면 build_prompt가 죽는다).

1. **역사·행 수·판정 날짜를 넣지 마라** — 받는 쪽은 맥락이 없다.
2. **말투는 형용사보다 본보기가 정확하다** — 승인본에서 하대·존대를 섞어 뽑는다
   (`approved_samples`). 한쪽 격만 보이면 산출이 그쪽으로 쏠린다. 본보기는
   `"본보기": true/false`로 박거나 뺀다 — **뽑는 줄이 결과의 전부다.**
3. **이야기의 전후를 조건으로 쓰지 마라** — `[맵>=147] …` 꼴로 적고 장면의 맵 번호로
   미리 풀어 해당 절만 보낸다(`resolve_conditions`).
4. **금지 예시를 쓰지 마라 — 원하는 대체 표현을 예시로 준다.** 금지문에 든 문구는
   산출에 그대로 샌다.
5. 용어집은 그 장면에 나오는 항목만 발췌한다(`glossary_for`). 지명도 고유명이다 —
   표에 없으면 새로 음차된다. 장면의 고유명은 현행 번역의 `<b>` 짝에서도 캔다.

## 산출 선별 — 사람이 볼 행만 추린다

전량 실행에서 행마다 사람이 판정할 수는 없다. 선별은 두 층이고, 자동 채택 전에
선별분만 사람이 본다.

- **휴리스틱 층 `uv run translate/screen.py <out-dir>`** — 행 신호(중복어 · 의성어
  변경 · 용어 이탈 · 금지 호칭 · 경칭 추가 · 존칭 「~님」 변화 · 라틴 추가/소실 ·
  길이 급감 · 기계 반려)와 페이지 신호(같은 화자의 격이 장면 안에서 갈림 — 격을
  갈아 쓰는 화자는 말투 정본에서 읽어 제외). 산출 `<out-dir>/screen.jsonl`.
- **모델 층 `uv run translate/screen_llm.py <out-dir>`** — 원문 대조가 필요한
  지어냄·누락·비문·오역을 오류 자리 지적(GEMBA-MQM 꼴)으로 짚고, 그와 별도로
  호칭·격·직역투·어색을 `제안`으로 올린다. 오류는 근거를 원문 낱말로 댈 수 있을
  때만, 제안은 의심스러우면 올리고 페이지당 다섯까지 — 둘은 따로 센다. flash ·
  effort=low · 행당 약 $0.0004. 산출 `<out-dir>/screen-llm.jsonl`.
  백엔드는 `batch.py`가 정한다(`Z_BACKEND=openrouter`). 402를 만나면 즉시 멈춘다.

같은 화면이 **판정 요청**도 받는다 — 배치 산출이 아닌 자리를 골라 재료를 갖추는 법은
[text-pipeline](text-pipeline.md) 「판정 재료와 판정 요청」 절이다.

선별분은 검수 스튜디오로 본다 — `uv run translate/review_gui.py --out <out-dir>
[--port 8788]`. 파일럿처럼 전량을 볼 때는 `--all`(선별 무관 전 행 — 진도도 판정 수
기준으로 바뀐다), 두 산출을 견줄 때는 `--alt <다른 out-dir>`(다른 답을 낸 행에 대조
줄과 「넣기」 버튼이 붙는다 — 채택하면 「직접」 판정에 그 문안이 실린다), 이미
승인·보호된 이벤트 안의 자리를 일부러 다시 볼 때는 `--no-skip`(기본 필터가 숨기는
자리까지 표시 — 유실 재검용).
걸린 행만 장면 단위로 묶어 띄우고, 판정은 누를 때마다
`translate/batch/verdicts-<out이름>.jsonl`에 **자리마다 최종 한 줄로** 저장된다.
그 판정 기록이 정본이고 화면의 TSV 내보내기는 예비다. 화면이 주는 것 넷 —
승인 줄은 목록에서 감추고(헤더에 숨긴 수), 「이벤트 전체 보기」로 안 걸린 행까지 펼쳐
판정하고, 장면 머리의 **완료 체크는 이벤트-페이지 단위**이며(같은 이벤트의 다른
페이지가 딸려가지 않는다), 「조사 요청」은 `asks-<out이름>.jsonl`에 따로 쌓인다.
진도는 「처음 선별된 행 가운데 화면에서 빠진 수」로 센다 — 안 고른 행은 새 번역
채택이라 판정이 안 남으므로 판정 수로는 진도가 안 잡힌다.
배치는 요청 전문을 페이지마다 `<out-dir>/<cid>.req.json`으로 남기고, 장면 머리
「프롬프트 전문」 버튼이 그것을 모델이 받은 그대로 보여 준다 — 산출이 이상하면
번역 지시부터 의심할 수 있는 자리다.

**판정 반영은 `uv run translate/apply_verdicts.py <out-dir> [--events] [--write]`.**
기본은 미리보기다. 규칙은 **판정이 없으면 새 번역 채택**이고, 안전판 셋 — 기계 검증
반려·승인 줄·「보류/현행」은 현행을 지킨다(메모만 남긴 자리도 물음이 걸린 것으로 본다).
⚠ **이 기본값이 무는 자리 둘을 Z-54 전까지 손으로 가드하라**: ① fixlog 손수정은
안전판에 없다 — 반영 전에 `provenance.py build`를 다시 만들고 산출 폴더의 사람 판정
자리를 보호 목록에 명시하라(2026-08-13 유실 64자리 실사고). ② 산출 파일의 `old`가 현행
정본과 다르면(낡은 스냅숏) 무판정 행이 옛 값을 재반영한다 — 미리보기의 반영 대상에
문맥 행이 섞여 있으면 그 행들에 「현행」을 깔고 돌려라(같은 날 3행 실사고).
`--events`는 판정이 끝난 이벤트만 반영하고 승인 이벤트와 **보호(page 단위)**에 올려
화면과 다음 배치에서 함께 뺀다. 같은 (맵,원문) 열쇠에 판정이 엇갈리면 반영하지 않고
목록으로 보여 준다. 4분 주기로 이 명령 → `verify.py` → 커밋을 돌리면 검수 중에
그때그때 반영된다.

**쓰기는 stage0를 지난다**(2026-08-18 전환, Z-53 3단계의 첫 도구). 값은
`stage0/messages.jsonl`에 앉고 `translate/ko/`는 emit 역생성이 낸다 — 옛 경로와
바이트 동치는 판정 묶음 여덟으로 실측됐다. 돌리기 전 둘이 서 있어야 한다:
`translate/ko/`에 미커밋 수정이 없고, stage0가 ko보다 낡지 않았어야 한다(낡았으면
`uv run translate/stage0/gen.py` 재흡수 후 커밋). 도구가 둘 다 검사해 어긋나면
쓰기 전에 멈추고 길을 알려 준다.
⚠ **산출 파일 이름은 `p…`(주연)·`t…`(트레이너) 둘 다다** — 도구가 한쪽만 훑으면
아무것도 반영하지 않고 이벤트를 승인으로 올려 판정이 조용히 사라진다(2026-08-06 실측).

곁에 두는 도구 둘 — `mend_newlines.py`는 원문에 없는 줄바꿈을 지워 「직접」 판정으로
미리 채운다(실측 104/104가 나머지 검사를 통과). `batch_trainers.py`는 이름표 없이
스프라이트로만 화자가 붙는 배틀 트레이너 대사를 도전·패배 한 벌로 묶어 보낸다
(256이벤트 532행, 페르소나표 부착).

성적(사람 정답지 실측): train(2차 133행)에서 두 층 합집합이 기계로 잡아야 할 하드
오류 9/9 · 선별률 14%, valid(3차 107행)에서 하드 1/1 · 선별률 4%. 1차 장면 319행에서
모델 층이 홀로 짚은 10행 중 7행이 유지자가 새 번역을 안 고른 행이었고, 그 몫의
대부분이 제안 갈래다. **밋밋한 재작성 같은 취향 층은 안 걸린다**(train 양성 40 중
26이 그 층) — 그건 승인 줄 보호·실기·제보 몫이다. 휴리스틱 층의 적중은 상당수가
`기계 반려` 플래그가 비친 것이니 품질 신호로 읽지 마라. 선별기의 힘은 표기 목록의 두께에
비례한다 — 새 이름이 나오면 목록부터.

프롬프트 본문의 「Naturalness rules」(J~Q)는 유지자 손수정 코퍼스에서 추출한
직역투 해소 규칙이다 — 문두 연결 부사구 삭제 · 관용구 대 관용구 · 명사구 사슬
해체 · 잉여 지시사 억제 · 확인창 자문형 · 본가 정형구 우선 · 울음소리 한국어
종명 재생성 · 관계절 범위. 규칙을 고치면 **파일럿(`--pilot`)으로 먼저 재고**
전량을 돌린다.
