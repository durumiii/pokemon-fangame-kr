# 2026-08-17 조사 스크립트 (박제)

Z-70(표기 통일)과 사각지대 실측에 쓴 1회용 스크립트다. **상비 도구가 아니다** —
`translate/` 아래 도구와 달리 손보지도, 다시 돌 것을 기대하지도 않는다. 여기 두는 이유는
하나다: 같은 날 커버리지 조사에 쓴 스크립트가 세션 scratchpad에만 있다가 사라져,
그 결과(어긋남 76행)가 왜 헛것이었는지 밝히는 데 값이 더 들었다.

돌리려면 `pokemon-z/`에서 `python3 docs/log/research/2026-08-17-scripts/<파일>`. 경로는
`translate/`·`docs/`를 상대로 잡는다. 산출은 그 세션의 scratchpad를 향하니 필요하면 고쳐 쓴다.

| 파일 | 무엇 |
|---|---|
| `z70_check.py` | 어긋남 76행의 「본가」 값이 코퍼스 어느 세대에서 온 것인지 대조 |
| `find_splits.py` | 정본 전체에서 같은 표현의 두 표기(띄어쓰기·수 구간)를 전수로 뽑는다 |
| `z70_count.py` · `z70_adjudicate.py` | 두 표기의 세대별 등장 횟수를 세고 최신 세대 쪽을 채택안으로 매긴다 |
| `z70_analyze.py` | 변수(보간) 든 문장의 규모와 자리표 정규화 재대조 |
| `z70_fuzzy.py` | 원문이 미묘하게 다른 자리를 유사도로 맞춘다(문턱 0.85, 앞 두 낱말 블로킹) |

세대 랭크는 전부 `translate/canon_sweep.py`의 `SRC_RANK`를 그대로 쓴다 — 그것을 안 쓴
대조가 헛것을 낳는다([경위](../2026-08-17-corpus-divergence-generational.md)).
