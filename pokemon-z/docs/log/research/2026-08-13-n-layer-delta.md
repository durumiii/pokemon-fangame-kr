## 3. 박제 수치는 왜 안 맞나 — 재현 실패의 범위

`sweep.py`가 문서에 적힌 규칙의 자유도 셋(숫자 그림 판정 3 × 이름표 걸러내기 4 × 접두 제외 2)
= **24판**을 전수로 돌렸다. **1,791페이지/3,088행을 내는 조합은 없다.**

```
숫자=첫자리숫자 이름표=대문자+방위+색 접두=trchar+rayos → N 1802페이지 3209행   ← 내 판
숫자=첫자리숫자 이름표=대문자만       접두=trchar+rayos → N 1792페이지 3199행   ← 페이지 최근접
숫자=숫자안봄   이름표=안거름         접두=안거름        → N 1595페이지 2800행   ← 최소
```

가장 가까운 판이 페이지는 1개 차이로 붙는데 행은 111개가 남는다 — 규칙 자유도로 설명되는
모양이 아니다. 세는 법도 아니다: 페이지의 `n_msg` 합과 `kind=="text"` 행 수가 층별로 정확히
같다(N 3,209 = 3,209).

**박제 자체가 커밋된 표와 어긋난다.** 박제 §6.1의 교차표를 `scene`별로 합치면 컷신 8,034행 ·
잡담 6,388행인데, 커밋된 귀속표는 컷신 8,029 · 잡담 6,393이다(수선 전후 동일). `scene`은 이번에
