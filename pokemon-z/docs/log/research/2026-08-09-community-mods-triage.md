# 2026-08-09 — 커뮤니티 수정판 셋 선별 조사

유지자가 가져온 커뮤니티 산출물 셋(레딧 수정판 Scripts · 디시 상성턱받이+디버그 Scripts ·
디시 페이크몬 개조 zip)을 서브 셋이 병렬로 뜯었다. 핵심 주장은 부모가 실물 diff·CRC로
재확인했다. 여기서 나온 티켓: Z-35 · Z-36 · Z-37.

원본 대조 기준: 설치본 `V2.18/Data/Scripts.rxdata` — 이건 순정이 아니라 **우리 모드가
주입된 빌드**다(Z-32 Ruby Compat + MOD 열다섯 섹션 실림, 실측). 아래 diff 판독은 그걸
감안해 읽었다.

## ① 레딧 자체수정판 Scripts.rxdata (실측)

- **베이스가 다른 게임이다.** 한국어 언어 옵션이 없고 UI 문자열 상당수가 중국어
  (부모 재확인: Settings diff에 `道具`·`药品` 등). 댓글의 「Pokemon Z 1.55」 표기와
  정합 — 우리 V2.18 계열이 아니다. 통짜 병합 시 우리 한글 모드·호환 층이 전부
  사라진다. **폐기 판정 재료.**
- 유효 변경은 하나뿐: `Settings`의 `MAPVIEWMODE = 1 → 0`(맵 렌더러를 커스텀에서
  원본으로). 주석 실측: `0=original, 1=personalizado, 2=perspectiva`. 사용처는
  `PScreen_Options`의 `def tilemap; return MAPVIEWMODE; end` 한 곳. Joiplay 렌더
  깨짐을 원본 렌더러로 우회하는 스위치로 판독(동작 개선 자체는 웹1소스+추정).
- 배포자가 주장한 「야생 조우 암전 단축」·「기술 상성 표시 추가」는 후보 파일들에서
  근거를 못 찾았다(전수 아님 — 후보 위주, 미확인). 상성 표시는 오히려 우리 빌드에
  있는 데미지·상성 표시(`pbHPChanged` 확장 인자)가 깎여 있었다(실측).
- 덤: 비트맵 로드·이벤트 실행마다 `Time.now`를 재고 로그 파일을 쓰는 프로파일링
  코드(`StoryLoadMetrics`)가 남아 있다 — 성능 개선이 아니라 오버헤드 방향(실측).

## ② 디시 상성턱받이+디버그 Scripts.rxdata (실측)

출처: 레쿠쟈 갤 228378 「상성턱받이 패치」(웹1소스 — WebFetch 요약 경유).

- 베이스는 순정이 아니라 **우리 한글패치의 이른 시점 합본 배포물**(UI Text KR·
  DPPT Font 섹션 실림, 너즐록 「영웅」 표기 수술 이전 문구 — 정황). 역시 통짜 금물.
- 커뮤니티 몫은 섹션 셋뿐:
  - `Bui`(131줄) — 배틀 기술 선택창에서 상대 타입 상성 배율을 계산해 기술 버튼을
    색칠(0배 검정 · ≤0.25 빨강 · <1 주황 · 2배 초록 · ≥4배 하늘). 더블배틀은 최저
    배율 기준. `FightMenuButtons`·`FightMenuDisplay`를 **alias 없이 재정의**.
  - `Db` — `Win32API GetAsyncKeyState`로 W키 폴링, 눌린 순간 `$DEBUG` 토글 + 안내
    메시지.
  - `디버그 모드/001_HealAfterBattle.rb` — `$DEBUG`일 때만 전투 종료마다 파티 전원
    회복(alias 방식).
- 충돌 조사: 세 섹션이 만지는 클래스(`FightMenuButtons`·`FightMenuDisplay`·
  `Scene_Map`·`pbEndOfBattle`)를 현행 MOD 섹션 전체에서 grep — 매치 0건(실측).
  지금 시점 충돌 없음. 단 `Bui`는 alias 없는 완전 덮기라 이후 배틀 UI 모드와의
  로드 순서 위험은 남는다.
- **미확인**: `GetAsyncKeyState`가 mkxp-z/Joiplay(모바일)에서 실제 키를 읽는지.
  엔진이 Win32API를 광범위하게 쓰므로 크래시 없는 스텁일 공산이 크지만 실기 확인 전
  단정 금지.

## ③ 디시 페이크몬 개조 zip (실측 + 웹1소스)

출처: 레쿠쟈 갤 228371(작성자 하나의용). 852MB zip.

- 정체: **우리 v5.2 한글패치(2026-08-06)가 설치된 게임 통짜 압축 + 유저 개조.**
  zip 안 mod.json이 「포켓몬 Z 한글 패치 v5.2」(실측), 동봉 번역표
  `01-species.jsonl`이 우리 정본과 CRC 동일 `0xfbf52143`(부모 재계산으로 교차).
- 개조 층 셋(기준 zip과 central directory CRC 전수 대조 — 추가 92 / 삭제 66 / 변경 203):
  - **PBS** — 킬리아(281)·솜솜코(189)·샤로다(497)의 타입·종족값·기술·특성 개조

  - **Graphics** — 해당 종들의 배틀러·아이콘 등 교체.
  - **한글 이름(「킬기시아」 등)** — PBS도 번역표도 아닌 `korean.dat`에만 산다

    회수 경로는 우리 `harvest.py` 그대로.
