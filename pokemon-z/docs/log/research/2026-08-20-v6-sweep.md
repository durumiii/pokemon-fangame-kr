# V6 배포 전 변경점 전수 취합 (2026-08-20)

유지자 지시로 v5.2.1(2026-08-07) 이후 쌓인 변경점을 전부 모았다. 결과는
`docs/CHANGELOG.md` 미공개 절 보강(이 날짜 커밋)과 아래 확인 목록이다.
릴리스 노트 초안은 [초안](2026-08-20-v6-release-note-draft.md).

## 방법과 커버리지

- **git 갈래**: v5.2.1 이후 커밋 699개(그중 08-09 이후 465 + author date 08-09 178)를
  서브 하나가 변경점 단위로 묶어 미공개 절과 전수 대조. docs/chore/merge 약 294개는
  제목만 보고 부속으로 분류했다(그 안에 정본 변경이 섞였다면 놓쳤다).
- **트랜스크립트 갈래**: 2026-08-09 이후 세션 121개의 축약본(transcript-digest, 총
  약 8.7MB)을 날짜 버킷 7개로 갈라 서브 병렬로 판독. git에 안 남는 행동(설치본 주입·
  자산 교체·외부 서비스·릴리스)과 유지자 판정을 추출했다.
- 기준선 확정: **V6 합본의 기준선은 v5.2.1이다.** mods-z-v2.1(08-09)은 모드 채널로만
  낸 판이라(합본 zip 미배포) 제외되는 것은 모드 산출물(글꼴·박힌 문구 치환표·Z-21·24·
  31·32)뿐이고, 같은 시기의 번역 정본 작업은 전부 미공개 몫이다.

## V6 배포 전 확인 목록

1. **미푸시 커밋** — 이 저장소 main이 origin보다 11개 앞선다(08-19~20 작업분).
   poke-essentials도 8개 앞서고, 거기 최근 커밋(도감 패드 아이콘·원본 팔레트)은 이번
   취합 범위 밖이라 내용 미확인.
2. **재조립 필수** — v5.3 zip 네 벌은 08-09 조립본이다. 그 뒤 정본이 대폭 바뀌었으니
   Z-34 티켓의 재개 순서(`make-patch-mod.py` → `patch_ruby_compat.py` →
   `make_package.py`)로 다시 조립한다. 배포 대기 조건(「번역 더 하고」)은 2026-08-18
   유지자가 해제했다.
3. **동봉 구성** — 유지자 판정(2026-08-20): Battle Order · Battle Scene Speed ·
   Better Movements · Bridge Fix · Map Cursor Snap · Type Matchup을 **Utility Pack**
   하나로, UI Text KR · Z-GUI를 **하드코딩 원문을 다루는 모드** 하나(이름 미정)로 통합해 여덟을 둘로
   동봉한다. 남은 판정: 디버그 추가판 동봉 여부(Z-34 이월 미결) · 통합 모드 이름 ·
   판 이름(v5.3으로 조립돼 있는데 유지자는 V6로 부른다). 통합 조립 작업 자체가 신규
   일감이다(make_package 재편).
4. **실기 확인 잔여** — Type Matchup(변화기 무색·더블 갈림 무색) · Map Cursor Snap ·
   Bridge Fix · Z-74 자산 화면 · 08-19~20 문안 반영분 · 상점 갈래. ⚠ 모바일(루나·
   조이플레이) 실기 확인 기록이 저장소에 없다(Z-34 티켓 경고).
5. **읽어주세요.txt** — 머리 판 번호가 v5.2.1로 남아 있다는 지적(08-13)이 있었다.
   조립 시 노트와 함께 갱신한다(release 지침 4항).
6. **모드 채널 배포 대기** — Type Matchup 단순화판·Map Cursor Snap(08-20).
7. **정본 관리 반쪽 구멍** — Z-74 자산의 원본 PNG 실물이 git에 없고 모드 보관소에만
   있다(08-19 세션 지적, 후속 미확인). 문안 원장·생성기는 repo에 있어 재생성은 된다.
8. **미판정 잔여** — fixlog 대 정본 어긋남 32줄(08-16 실측, Z-54) · 맵262(어둠의 탑
   P2) 자루귀신 층 판정 보류 · Z-64(맹독/독 아이콘, 손댈지부터 판정).

## 한계

- 트랜스크립트 갈래의 「이행됐다」는 세션 내 자체 기록이 근거다. CHANGELOG에 새로
  올린 항목은 전부 커밋 실물(`git show --stat`)로 대조했지만, 설치본·보관소의 실물
  상태는 재확인하지 않았다(어차피 재조립이 덮는다).

  작업은 시야 밖이다. 조사 산출 원본(버킷별 보고 7벌)은 세션 스크래치에만 있고
  요지는 이 문서와 CHANGELOG로 이관했다.
