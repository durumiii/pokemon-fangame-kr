## 손대지 않은 둘

**227:1:112 페로파스 「평화, 고요...」** — 체언 두 개를 나열한 조각이라 고칠 종결어미가
없다. 목록의 「지금 = 존대」는 분류기 오탐이다. `translate/reg.py`의 `classify`가 마지막
어절 「고요」의 끝 음절을 해요체 「~요」로 읽는다:

```
$ python3 -c "import sys; sys.path.insert(0,'translate'); from reg import classify; print(classify('평화, 고요...'))"
('해요', '고요')
```

**276:43:21 안투리아 「이제 시작해 볼까?」** — 이미 반말이다. 커밋 7932d3f(「트레이너
개시·패배 말투 정합 69곳」)가 「이제 시작할까요?」를 지금 값으로 바꿔 놓았다. 목록의
「지금 = 존대」는 그 커밋 이전 상태다.
