### 1.4 결론 — 급 통일 배치가 덮은 범위와 실제 층의 차이


**의견: 풀을 다시 떠야 한다.** 근거 셋이다.

다만 **전량 재작업을 뜻하지는 않는다.** 교집합 3,441행은 이미 한 판 지났으니, 새 물결은

### 2.2 (a) 행 단위 급 분류 채점

| 수준 | 결과 |
|---|---|
| **7급 정확도** | **50/58 = 0.862** (라벨이 「그 줄만으로 못 정함」·「시스템」인 6건 제외) |
| **2치(존대/비존대)** | **50/50 = 1.000** (양쪽 판정 불가를 뺀 50건) |
| 그 줄만으로 급을 못 정하는 줄 | 64건 중 6건(9%) — 무표지 「~네/~군/맨 ~다」. 지침이 이미 「행 단위로 급을 단정하지 마라」고 적은 그 자리 |

**틀린 8건이 네 원인으로 뭉친다.**

| 원인 | 건 | 실물 |
|---|--:|---|
| **`speechy()`가 인칭 표지를 놓친다** | 2 | 「그런 몬스터볼은 **우리가** … 놓아둔 덫이다」(B5로 떨어짐) · 「**네** 포켓몬 모험은 여기서 끝이다!」(B5) |
| **마지막 문장만 보아 앞 문장의 급 표지를 버린다** | 3 | 「영특하**구나**, … 배틀을 할 차례다!」(B4→B5) · 「… 무슨 말인지 **알지**?」 앞이 「가까워졌다」(B1→B5) · 미라 「그렇다! 신성한 상징이**다**! … 룬이다」(B7→B5) |
| **굽은 따옴표(“ ”)가 종결부호 목록에 없다** | 1 | 「… 깨닫는 것**입니다**.”」 → `final_chunk`가 `”`를 못 떼 합쇼 판정 실패 |
| **회상·나열 종결 미지원** | 2 | 「… 특성이 뭐였**더라**?」(판정 불가) · 「제르네아스, 이벨타르, 지가르**데**...」(나열인데 「데」로 해체 판정) |

`speechy` 결함은 정규식으로 확인된다 —
`SPEECHY = (나|난|내|내가|나도|우리|너|너희|네가|네게|네겐|넌|널|니가|당신|자네|그대)(?![가-힣])`.
`우리`는 있지만 뒤에 조사 `가`가 붙으면 `(?![가-힣])`가 막고, 관형격 `네`(「네 포켓몬」)는
목록에 아예 없다. 실측:

```
speechy("우리가 놓아둔 덫이다.")            → False
speechy("네 포켓몬 모험은 여기서 끝이다!")   → False
speechy("내가 간다.") · speechy("우리 마을이다.") → True
```

**방향**: 8건 중 5건이 「대화인데 B5지문평서로 떨어뜨림」이다. B5는 「사람 화자 아님」 급이라
이 오류는 **인물 대사를 무인칭 지문으로 누르는 쪽**으로 샌다 — 1부에서 잰 「말투 소실」과
같은 방향이다.

### 2.3 판정 불가 행의 규모와 정체

세는 법: 정본 고유 원문 11,157개에 `axis`/`grade`를 돌려 빈 결과를 센다.

```
axis 판정 불가 1,403 / 11,157 = 12.6%
grade 분포  B1반말 4,532 · B2해요 1,736 · 판정불가 1,403 · B5지문평서 1,374 ·
            B3합쇼 1,184 · B7대화단정 349 · B4어른말 314 · B6하게 265
판정 불가의 꼴  기타 978 · 말줄임 종결 255 · 체언 종결 90 · 3자 이하 64 · 한글 없음 16
```

**「짧은 행·감탄사」가 아니다** — 1,403 중 978(70%)이 그 어느 꼴도 아닌 평범한 문장이다.
무작위 25건을 읽으면 급이 뚜렷한 줄이 절반 넘는다:

| 놓친 줄 | 왜 |
|---|---|
| 「내 역할이 딱히 눈에 띄지는 않**네만**...」 | `~네만` 미지원 |
| 「… 마음을 다해 대접해 드리겠**소**.」 | **하오체 전체가 규칙에 없다** |
| 「너도 제법 강해 보이는데 … 한 판 겨뤄보는 건 **어때**?」 | `~어때` 미지원 |
| 「… 없을지도 모릅니다, **대장님**.」 | **문미 호격**을 못 뗀다(`VOCATIVE_KUN`이 「~군」만 처리) |
| 「나도 마찬가지다, **아스테르**.」 | 같은 문미 호격 |
| 「왜 아직도 무릎을 꿇지 않는 거**지**?」 | `AMBIG` 물러나기가 빈손이면 `axis`는 버린다(`grade`에만 `lenient` 갈래가 있다) |

즉 판정 불가 12.6%는 **분류기의 표(어미 목록)가 덜 찬 것**이고, 문미 호격과 하오체 둘만
메워도 눈에 띄게 줄어든다.

### 2.4 (b) 이벤트 내 어긋남 검출 채점

`R.scan()` 반환값(문서 안 씀):

```
scan이 실제로 판정한 행    3,608
어긋남으로 찍은 것           159
건너뛴 것  이중말투 3,777 · 급 판정 불가 796 · 표본 부족 148 · 평소 급 갈림 110 · 번역없음 1
```

**구조상 회수율은 「건너뛴 4,832행」에만 달려 있다** — scan은 판정한 3,608행 가운데 평소 급과
다른 것을 **전부** 찍기 때문이다. 그래서 정밀도는 찍힌 쪽에서, 회수율은 건너뛴 쪽에서 쟀다.

**정밀도 — 찍힌 159건 중 무작위 16건 판독**

| 판정 | 건 |
|---|--:|
| 진짜 어긋남 | **3** (맵356 현자 합쇼 · 맵362 클렘 반말 「느껴지려고 해!」 · 맵217 안젤린 해요) |
| 경계(혼잣말·상황 의존) | 2 (맵90 볼프람 혼잣말 「깜빡했군!」 · 맵228 피노 「되지요」) |
| **헛짚음** | **11** |

정밀도는 표본 16 기준 **3/16 = 0.19**(경계를 참으로 쳐도 5/16 = 0.31). 헛짚음의 원인은 셋뿐이다.

| 원인 | 표본 건 | 모집단 |
|---|--:|--:|
| **역할 이름표를 한 화자로 뭉친다** (`???`·`Ciudadano`·`Mosquetero`…) | 5 | 159건 중 **45건** |
| **평소 급을 3~11줄로 정한다** | 4 | 159건 중 **45건**(표본 12줄 미만) |
| **상대에 따라 격이 갈리는 인물인데 `DUAL` 목록에 없다** | 2 | 미라(383행)·메를로 대장(39행) 등 |

셋을 합치면 159건의 절반 이상이 설명된다. 세는 법은 `R.scan()` 결과에
`Counter(r['who'] in 역할이름표), Counter(r['n']<12)`.

`DUAL` 목록의 결함은 실측으로 두 가지다.

```
DUAL = {Lanto, Crisanto, Melia, Olivier, Aure, Merlot, Hisopo, Cendera, Pinot}
이름표 실물:  Merlot 38행 / Capitán Merlot 39행(DUAL 밖) ·
             Pinot 0행(DUAL의 죽은 항목) / Alcaide Pinot 25행(DUAL 밖) ·
             Cendera 26행 / Capitana Cendera 10행(DUAL 밖) · Loto 18 / Capitán Loto 16(둘 다 밖)
```

① **직함이 붙은 이름표 꼴이 목록을 빠져나간다**(정확 문자열 비교). `Pinot`은 0행이라 아예
죽은 항목이고 실제 자리는 `Alcaide Pinot` 25행이다.
② **voices.md가 「상대에 따라 갈린다」고 적은 인물이 목록에 없다** — 미라(383행, 「국왕·스승
아우레를 뺀 대부분에게 하대」) · 히비스 · 볼프람(자동인형에게만 하대) · 로토 · 마담 칼렌둘라.
어긋남 상위 화자에 `Mirra` 14건 · `Wolfram` 8건이 그대로 올라온다.

**1건**(맵266 미라 「끝내야 하오」 — 하오체 미지원)이고 그마저 voices.md 규칙상 정상인
자리다. 나머지 11건은 급이 없거나(「...」·「꺄아아아악!」) 평소 급과 같았다.
**「급 판정 불가」는 회수율 손실이 작다.**

⚠ **진짜 사각지대는 「이중말투 3,777행」이다.** scan이 아예 안 보는 행이 판정 행(3,608)보다
많다. 이 층은 설계상 제외지만, 그 안의 어긋남은 도구가 있든 없든 0건 검출이다.
이번 조사에서 이 층은 표본을 안 떴다(미측정).

### 2.5 결론 — 무조건 게이트로 세울 수 있나

**지금 그대로는 안 된다.** 두 방향의 새는 양이 이렇다.

| 방향 | 크기 | 성격 |
|---|---|---|
| **헛짚음(위양성)** | 찍힌 159건의 **69~81%** | 사람이 159건을 다 열어 보고 그중 3~5건만 건진다. 게이트로 세우면 검수 비용이 실익의 30~50배 |
| **못 봄(위음성)** | 이중말투 3,777행 전량 + 판정 불가 796행의 일부 | 정본 인물 아홉의 어긋남은 도구가 0건 검출 |
| **행 급 자체** | 7급 86% · 존대/비존대 100% | 존대·반말 경계 판정에는 이미 쓸 만하다 |

**보강 지점을 값싼 순서로.**

1. **역할 이름표를 화자로 쓰지 마라**(`???`·`Ciudadano`·`Mosquetero`류). 이름표 하나에 여러
   사람이 서므로 「평소 급」이 성립하지 않는다. 159건 중 45건이 여기서 사라진다.
   `???` 자리는 `translate/data/2026-08-06-anon-speakers.jsonl`의 전수 판정본이 이미 정체를
   갖고 있으니 그것으로 화자를 갈라 쓴다.
2. **평소 급의 최소 표본을 3줄에서 12줄로 올려라.** 지금 159건 중 45건이 3~11줄짜리 근거
   위에 서 있다(맵25 포켓몬 간호사는 3줄로 「평소 반말」이 되어 정상 존대 두 줄을 찍었다).
3. **`DUAL`을 문자열 비교에서 「이름 포함」으로 바꾸고 voices.md 로스터에서 채워라** —
   `Capitán Merlot`·`Alcaide Pinot`·`Capitana Cendera`·`Capitán Loto`가 지금 새고,
   `Pinot`은 죽은 항목이며, 미라·히비스·볼프람·로토·마담 칼렌둘라가 빠져 있다.
4. **`speechy`에 조사 결합을 허용하고 관형격 `네`를 넣어라** — 대화가 B5지문평서로 눌리는
   오류 다섯 중 둘이 여기서 온다.
5. **문미 호격과 하오체를 분류기에 넣어라** — 판정 불가 12.6%의 큰 몫이다.

**세울 수 있는 자리**는 따로 있다. 존대/비존대 2치는 표본 50건에서 한 건도 안 틀렸다.
「이벤트 안에서 존대·반말이 정면으로 갈리는가」만 묻는 **좁은 게이트**라면 지금도 선다 —
어긋난 급이 무엇인지, 어느 줄이 잘못인지까지 판정하려 들 때 위양성이 터진다.
