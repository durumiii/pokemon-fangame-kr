# 본가 상성 라벨의 더블배틀 동작 — 영상 프레임 실측 (2026-08-20)

Type Matchup 모드를 본가식으로 단순화하며 「본가 더블에서는 색 처리를 어떻게 하나」가
설계 갈림이 됐다. 텍스트 웹 조사 세 바퀴(일반 위키·VGC 커뮤니티·일영한 공략·스크린샷
페이지)가 전부 침묵이라, 스칼렛바이올렛 랭크 더블 실황 영상에서 프레임을 떠서 판독했다.

## 확정 (프레임 실측, 영상 둘 교차)

- **더블 기술 선택창에도 라벨이 뜬다 — 기술마다 따로, 그 기술의 현재 기본 대상 기준.**
  같은 화면에서 악 기술만 골든기(강철/고스트) 기준 「Super effective」, 나머지 셋은
  무크로우(악/비행) 기준으로 뜨는 프레임을 확인했다. 즉 「고정된 한쪽 상대 기준」이
  아니다. 기본 대상이 어떻게 정해지는지(마지막 사용 대상 기억설)는 1회 관측 기반
  추정으로 남았다.
- **대상 선택 화면에서는 네 칸(상대 둘+아군 둘) 전부 대상별 라벨이 따로 뜬다** —
  「Has no effect / Effective / Not very effective」가 칸마다 갈리는 프레임을 두 영상에서
  확인했다.
- 근거 영상: youtube.com/watch?v=WPjNXWTj14w (SV 랭크 더블, 105~111초 구간 —
  기술창 108초 · 대상 선택 105·111초) + BrandonMVGC 채널 랭크 더블 영상 6:39경 교차.
  프레임 파일은 세션 스크래치에만 있었다 — 재확인은 위 시각으로 다시 뜬다.

## 확정 (웹 2소스 교차)

- 라벨 기능은 7세대 썬·문 도입. **도감에 등록된(싸워 본) 상대만** 표시되고,
  배틀타워·온라인 대전은 조건 없이 항상 표시(썬문·소드실드 확인).

## 미확인으로 남은 것

- 변화기에 라벨이 붙는지 (어느 출처도 침묵 — 우리 모드는 색 없음으로 판정).
- 기술별 기본 대상의 결정 규칙.

## 모드에 옮긴 판정 (유지자, 2026-08-20)
