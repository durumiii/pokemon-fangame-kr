# 애매 층 flash 트리아지 결산 (2026-08-09, Z-40)

잡담 분류 3층 게이트([채점판](2026-08-09-scene-scorer.md))의 애매 층을
`deepseek/deepseek-v4-flash`(OpenRouter, 온도 0, JSON 강제)로 전량 분류했다.
1,478건 완주, 오류 0, 비용은 1달러 미만.

## 애매 층의 실제 크기와 구성

티켓의 「약 1,830페이지」는 이름표 페이지 349건을 합친 수(1,827)였다. 이름표
페이지는 voices.md 영역이라([events-and-speech](../guides/events-and-speech.md)
「잡담의 경계」) 트리아지에서 뺐고, 실제 대상은 **1,478페이지**다.

구성이 예상과 달랐다: 엄격 필터 탈락 사유가 전부 **스프라이트 증거 부재**였다 —
스프라이트 없는 이벤트 790 + 사물 스프라이트(열매·바위·상자 등) 688. 대사 수나
트리거로 탈락한 페이지는 0. 즉 이 층은 「그림으로 사람인지 알 수 없어 텍스트로
판정해야 하는」 페이지들이고, LLM 트리아지가 정확히 맞는 도구였다.
(재현: 전수 특징표에서 scene=잡담 · strict=False · has_tag=False.)

## 결과

| 라벨 | 건수 | 처분 |

| 시스템지문 | 1,282 | 제외 층으로 확정 |
| 잡담 | 87 | 통과(편입 후보) |
| 스토리 | 69 | 통과 — 유지자 정의(스토리=메인스토리 이벤트)로 재해석 |

**통과 192 / 제외 확정 1,286.** 애매 층의 87%가 시스템지문 — 사물·투명 이벤트가
주로 표지판·조사 문구라는 뜻이고, 층 설계의 예상과 부합한다.

## 통과분의 품질 한계 — 확실 층과 동급이 아니다

채점판의 flash 94.3%는 **사람 스프라이트 페이지 88건**에서 잰 수치다. 이 층은 분포가
다르고(스프라이트 부재·사물), 표본 검사에서 오수용이 실제로 보였다: 쓰레기통 조사
문구(「여기엔 쓰레기밖에 없다」, Casa 두 자리)와 미술관 명판(「Autora: 린쿠」)이
잡담으로 통과했다. 방향은 채점 때와 같은 시스템→잡담 오수용이고 말투 축 위험은
낮지만, **통과 192를 확실 층(정밀도 90.9%)과 같은 등급으로 취급하지 말 것.** 배치
재번역(Z-4)에서 쓸 때는 페이지 전문이 어차피 프롬프트에 실리므로 그 단계의 검수가
이중 안전망이다.

## 말투 선제 교정 2차 — 확장분 0건으로 확정

1차 승인 방향의 스프라이트 다섯(burguesow · curanderaow · gitano ·
mosqueteraMontada · mosqueterow)은 통과 192건에 **한 건도 없다**(전부 스프라이트
부재·사물이므로 당연하다). 승인 스프라이트의 비-엄격 페이지 전수도 트레이너 배틀
34 · 컷신 2 · 대화 4뿐 — 모두 설계상 제외 층이다. 즉 **이 게이트 확장으로 새로
생기는 말투 교정 후보는 없다.** 남는 유지자 몫은 1차의 보류 2건(revolucionario
진행도 의존 말투, mosqueterow 카페 교환 첫 줄)뿐이다.
