# V6 릴리스 노트 초안 (2026-08-20)

⚠ **초안이다.** 배포 zip을 아직 안 조립했다 — release 지침대로 조립 후 zip을 열어
실린 것만 남기고, 규모 숫자는 태그 diff로 다시 센다. `[확인]` 표시는 조립·판정
결과에 따라 걷어낼 자리다. 동봉 구성은 유지자 지시(2026-08-20) 기준: 하드코딩
원문을 다루는 모드 하나(UI Text KR + Z-GUI 통합, 이름 미정 — 본문 가칭 「UI 한글화」)와
Utility Pack(편의 모드 일곱 통합, Native Tilemap 포함). 디버그 모드·Controller UX는
v5.2.1의 「디버그 추가」처럼 별도 덮어쓰기 자산으로, 배포 zip은 글꼴별 하나씩(3종).

---

번역을 크게 손본 판입니다. 2주에 걸쳐 전면 검수를 여러 차례 돌렸고, 스페인어가
그대로 나오던 자리 여럿을 엔진 수준에서 고쳤으며, 그림에 박힌 글자까지 한국어로
다시 그렸습니다. 함께 들어가는 모드도 두 개로 정리해 구성이 단순해졌습니다.

## 번역

인물의 말투부터 화면 구석의 표기까지 한 벌로 맞췄습니다.

- **등장인물 말투 규범을 정교화했습니다.**
  - 등재 없이 남아 있던 화자까지 포함해 백여 명의 말투 규칙을 상대성 표로 확립하고 정본 수백 행에
    반영했습니다.
  - 한 인물이 한 대화 안에서 존대와 반말을 오가던 자리를 전수 정리했습니다 —
    NPC 격 널뜀 78행, 전투 전후 대사 맞춤 59행 등입니다.
  - 번역표 적용 엔진을 개선했습니다. 
  - 같은 문장을 여러 인물이 나눠 써서 지금까지 한쪽 말투를 포기해야 했던 자리를 화자별로 갈랐습니다. 
    상점·교환·회복 창구의 안내문이 그 창구를 여는 사람의 말투를 따르고(창구 대사 94줄), 훈련소처럼
    한 문장을 다른 인물이 쓰는 장면도 각자의 말투로 나옵니다.
- **본가 공식 표현 대조를 대사와 표기 전반으로 넓혔습니다.**
  - 기술·특성·도구 설명 590행과 도감 설명 103행을 수정했습니다.
  - 메뉴·UI 문구 440여 행 — 대화 선택지 「네」→「예」 265행, 메뉴 동사꼴 49행,
    「저장」→「리포트」 41행, 벽지·주머니·도감 라벨 등입니다.
  - 본가에 같은 문장이 있는 일반 대사 301자리를 공식 자구로 바꿨습니다(코퍼스
    사각지대 전수 조사).
  - 복합어 띄어쓰기·부호 표기가 줄마다 다른 세대를 따르던 520행을 최신 세대
    기준으로 통일했고, 도구 획득 문구 26건과 박스/PC 화면 95행도 맞췄습니다.
- **오역을 다수 바로잡았습니다.** 화면 표시와 실제 효과가 반대였던
  노력치 열매 문안 6쌍, 원문에 없이 끼어 있던 문두 감탄사 18행, 상점 수량이 물건처럼
  읽히던 문구 3갈래 등을 정리했습니다.
- **이름을 다듬었습니다.** 
  - [레쿠쟈 갤러리 통파일](https://gall.dcinside.com/mgallery/board/view/?id=rayquaza&no=228371) 의 페이크몬 이름 번역을 반영했습니다. 
  - 「알파」 계열은 본가 명칭 「우두머리」로, 상태이상 Caduco는 「쇠락」에서 「쇠약」으로, 「올리비에 교수」는 「올리비에 박사」로 수정했습니다.

## 스페인어로 남아 있던 자리를 한글화했습니다

- 게임 엔진을 수정해 번역이 적용되지 않던 문제를 고쳤습니다.
  - 맵을 이동한 뒤 말을 걸면 스페인어가 뜨던 문제를 고쳤습니다.
  - 트레이너 전투가 끝날 때의 대사 588곳이 번역을 타게 됐습니다.
  - 배지 이름 12개, 까메오 트레이너 169명의 이름이 한국어로 나옵니다.
- 스페인어·영어로 남아 있던 그림 72장을 한국어로 다시 그렸습니다. 
  - 인트로 텍스트, 보스 카드, 튜토리얼, 상장, 조작 안내, 가방의 「등록」 표시 등입니다.

## 버그 수정

- 다리를 한 번 건너면 다리 밑 물길을 파도타기로 지나갈 수 없던 원작 결함을
  고쳤습니다. 물 타일이 빠져 있던 19번도로 다리 밑도 함께 메웠습니다.
- 조작 설정에서 P키와 G키를 고를 수 없던 문제를 고쳤습니다.
- 하드 난이도 세이브에서 옵션 설명이 한 칸씩 밀려 보이던 원작 결함을 고쳤습니다.
- 모바일 실행기에서 굵은 한글을 그리다 튕기던 문제를 고쳤고, 루비 3.0+ 대비 호환성을 넓혔습니다.
- 조임 계열 기술(집게덫·소금절이·강철감옥·엉겨붙기)이 엉뚱한 문구를 쓰던 버그를 수정했습니다.

## 모드 구성이 바뀌었습니다

패치에 함께 들어가는 모드를 둘로 정리했습니다.

- **UI 한글화** — 화면 문구와 GUI 그림처럼 번역표 바깥에 박힌 원문을 한국어로 바꾸는 모드입니다.
- **Utility Pack** — 편의 모드 일곱을 하나로 묶었습니다.
  - **Battle Order**(신규) — 턴 중 스피드 변화 반영, 날씨/상태이상 데미지 문구 순서 등이 최신세대 기준으로 정상화됩니다.
  - **Bridge Fix**(신규) — 위 「다리 밑 파도타기」 수정입니다.
  - **Map Cursor Snap**(신규) — 리전 맵에서 작은 마을을 고르기 어려운 문제를 고쳤습니다.
  - **Type Matchup** — 상성 색 표시를 수정했습니다. 변화기는 색칠하지 않고, 일루전, 특성, 도구를 스포일러하지 않습니다.
  - **Better Movements** — 이동 조작 개선(기존 동봉분).
  - **Battle Scene Speed**(수정) — 기존 Battle Speed의 수정본, 기타 배틀 애니메이션을 모두 배속합니다.
  - **Native Tilemap** — 맵을 엔진 내장 렌더러로 그립니다. 일부 모바일 실행기
    (조이플레이 등)의 화면 문제를 우회합니다.

디버그 모드(P키·패드 토글로 켜고 끄는 통합판)와 패드 조작 개선(Controller UX)이
필요하시면 별도 zip을 받아 합본 위에 덮어씌워 주세요.

## 설치

배포본은 글꼴별로 하나씩입니다(DPPt · 갈무리 · BW). 원하는 글자체의 zip 하나만 받아
풀고, 게임 폴더에 그대로 덮으시면 됩니다. 모드킷으로도 설치 가능합니다.

## 지난 판에서 덮어쓰시는 분께

세이브는 게임 폴더 밖에 있습니다. 윈도우는 Saved Games 안의 Pokemon Z 폴더라,
게임 폴더를 통째로 지우고 새로 까셔도 진행 상황은 그대로 남습니다.

v5.x 위에 그대로 덮으셔도 됩니다. `[확인: 옛 모드 구성(개별 모드 파일)이 남았을 때
정리가 필요한지 — 조립 후 실측]`

## 아이폰·안드로이드에 넣으실 때

폴더를 통째로 옮기지 마시고, 폴더 안으로 들어가 파일만 덮어씌워 주세요. 파일 앱은
같은 이름의 폴더를 만나면 안을 합치지 않고 폴더째 갈아치웁니다. Data 폴더가 그렇게
갈리면 원판 맵이 통째로 사라져 게임이 켜지지 않습니다.

## 게임이 안 켜질 때

「읽어주세요.txt」에 자가진단 절차가 들어갔습니다 — 파일이 다 있는지, 게임 본체
판이 맞는지, 윈도우의 비유니코드 프로그램 언어 설정 순서로 확인하시면 됩니다.
