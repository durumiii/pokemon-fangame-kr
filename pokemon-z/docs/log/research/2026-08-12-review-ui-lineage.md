# 검수 UI의 두 세대와 「프롬프트 전문」 기능의 이관 누락 (2026-08-12 박제)

v5.2 재번역의 검수 화면은 두 세대를 거쳤다. 1세대는 세션 스크래치패드에서 만들어
Artifact로 게시한 1회성 HTML 페이지(`pilot-review.html`·`pilot2-review.html`, git
미추적 — 원본 소실)였고, 이를 재사용 가능하게 다시 짠 것이 지금의
`translate/review_page.py`/`review_gui.py`(2세대)다. 이 이력은 git만으로는 보이지
않는다 — 1세대가 저장소 밖 산출물이었기 때문이다.

1세대의 기능 여섯(문장 선택 · 직접 · 보류 · 메모 · 문맥 · **프롬프트 전문 A/B 탭**)
가운데 앞 다섯만 2세대로 이식됐고 프롬프트 전문 열람만 빠졌다. 데이터 쪽은 계속
살아 있었다 — 커밋 `fd05b34`(2026-08-06)가 요청 전문을 `<cid>.req.json`으로 남기게
했고, 그 커밋 메시지 스스로 「검수 페이지의 「프롬프트 전문」이 모델이 받은
그대로여야 하기 때문」이라고 용도를 밝힌다. UI만 이관에서 누락된 채 남았다.

2026-08-12 유지자가 파일럿 3차 검수 중 버튼 부재를 지적해 발굴 조사가 돌았고
(근거: v5.2 세션 축약본의 버튼 JS 조각, `.refresh-guides/2026-08-06-1130-pilot2-rerun.md`
의 기능 목록·재조립 스니펫), 같은 날 `review_gui.py`에 복원했다 — 장면 머리
「프롬프트 전문」 버튼이 `GET /req?cid=`로 req.json을 받아 문맥 모달에 세운다.

교훈은 지침·스킬로 갔다: 세션 산출(Artifact·스크래치패드·refresh 가이드)에 정본감
기능·절차가 남으면 세션 마감 때 승격을 점검한다(docs-upkeep 점검 목록).
