## 0. 방법과 표본 — 수를 어떻게 셌나

**세는 기준(실측).** 모든 수는 아래 스크립트가 낸 것이고, 재현 명령을 함께 적었다.
작업 파일은 전부 `/tmp/claude-1000/-home-durumii-workspace-claude-native-pokemon-fangame-kr/e8361145-d42f-492d-9df7-7ff5e679c340/scratchpad/` 아래에 있다.

| 파일 | 무엇 |
|---|---|
| `count.py` · `count2.py` · `count3.py` | 유형별 빈도 집계 스크립트 |
| `u-heavy.txt` · `u-mid.txt` · `u-small.txt` · `u-micro.txt` | 중복 제거한 재작성 쌍을 변형 크기별로 나눈 덤프 |
| `u-micro-nonterm.txt` | 미세 변경분에서 궁극병기→최종병기 일괄 치환을 뺀 117건 |

**표본 크기(실측).**

- 전체 1,052행 중 「현재」와 「제안」이 **둘 다 있고 서로 다른** 행: **904행**
- 이 904행을 (원문, 현재, 제안) 삼중키로 중복 제거하면 **616건**의 서로 다른 재작성 판단
- 차이가 큰 순서로 나누면(difflib 문자 유사도 기준): 크게 고침 67건 / 중간 118건 / 조금 198건 / 미세 233건

**중복이 많은 이유.** 같은 문구가 여러 자리에 서 있어 한 번의 판단이 수십 행으로 불어난다.
예를 들어 「궁극병기→최종병기」 한 판단이 141건, 「Exportar equipo」 UI 항목 하나가 자리 30곳에
걸려 있다. **따라서 아래 빈도는 전부 「고유 판단 수(uniq)」와 「제보 행 수(rows)」를 나눠 적었다.**
uniq가 판단의 다양성, rows가 실제 손댄 분량이다.

**전수인가 표본인가.** 유형 분류는 616건을 **전수로 눈으로 읽고** 매겼다. 정규식으로 셀 수 있는
유형(존대 어미, 앞머리 부사구, 로마자 잔존 등)은 전수 자동 집계이고, 관용구 교체나 어순
재배치처럼 기계로 못 잡는 유형은 **수작업 열거이므로 하한값**이다. 그런 항목은 표시해 두었다.

**길이 방향(실측).** 904행에서 제안이 현재보다 짧아진 것 399행, 길어진 것 246행, 같은 것 259행.

## 1. 유형별 패턴

### S1. 한 원문의 여러 번역을 하나로 수렴 — uniq 8, rows 75 (실측)

문체 축에서 **행 수로는 가장 큰 덩어리**다. 같은 스페인어 원문이 자리마다 다르게 번역돼 있던
것을 유지자가 문안 하나로 통일했다. 재현: `python3 -c` 로 원문별 「현재」 값 집합을 세면 된다
(위 count 스크립트의 마지막 블록).

가장 심한 사례 — 원문 하나에 번역이 **19종**:

```
원문 : No es seguro continuar llevando solo 1 Pokémon saludable en el equipo.
현재 : 배틀 가능한 포켓몬이 1마리뿐인 상태로 계속 진행하는 것은 위험합니다.
현재 : 지니고 있는 포켓몬 중 배틀할 수 있는 포켓몬이 1마리뿐일 때는 계속 진행하는 것이 위험합니다.
현재 : 기운이 있는 포켓몬을 1마리만 데리고 계속 나아가는 것은 위험합니다.
현재 : 팀에 건강한 포켓몬이 1마리뿐인 상태로 계속 나아가는 것은 위험합니다.
       … (총 19종, 제보 20행)
제안 : 배틀할 수 있는 포켓몬이 하나뿐인 채로 다가가는 건 위험하다.
```

무엇이 좋아졌나. 세 가지가 한꺼번에 정리됐다. ① `saludable`을 「건강한/기운이 있는/싸울 수
있는」으로 제각각 옮기던 것을 시리즈 표준어인 「배틀할 수 있는」으로 고정했다. ② 「1마리뿐인
상태로 계속 진행하는 것은 위험합니다」의 명사구 사슬(상태+것)을 「하나뿐인 채로 다가가는 건」으로
풀었다 — 조사 하나로 붙던 자리를 어미로 바꿔 읽는 호흡이 짧아진다. ③ 존댓말 지문을 평서형으로
내렸다(이 문구는 화자 없는 시스템 경고다).

같은 유형 다른 사례:

```
원문 : ¡Es un arbusto de bayas!
현재 : 나무열매 덤불이다! / 나무열매가 열리는 관목이다! / 열매 나무다! / 열매가 열린 관목이다! …(12종, 27행)
제안 : 나무열매 관목이다!
```

원문은 명사구 하나(`arbusto de bayas` = 열매 관목)인데 현재 번역은 절반이 「열매가 열리는 ~」으로
관계절을 만들어 늘렸다. 제안은 원문과 같은 명사구 하나로 되돌린다.

```
원문 : ¡Es un <b>Nido Alfa</b>! En él vive un Pokémon muy fuerte.
현재 : <b>알파 둥지</b>다! 그곳에는 / 이곳에는 / 이곳엔 아주 강한 포켓몬이 살고 있다. (4종, 15행)
제안 : <b>알파 둥지</b>다! 안에는 아주 강한 포켓몬이 살고 있다.
```

`En él`(그 안에)를 「그곳에는/이곳에는」으로 옮기면 지시 대상이 둥지인지 주변 지형인지 흐려진다.
「안에는」이 원문의 `en`을 정확히 받으면서 짧다.

### S2. 군더더기 삭제와 압축 — 유형 합계 uniq 40+ (실측, 유형별로는 아래)

**S2-a. 문두 부사구 통삭제 — uniq 16, rows 16.** 스페인어 `En concreto,`를 「구체적으로는,」으로
직역해 두었던 16개 타입 문구를 전부 삭제했다.

```
원문 : En concreto, sientes la presencia de un Pokémon Fantasma muy poderoso.
현재 : 구체적으로는, 매우 강력한 고스트타입 포켓몬의 기운이 느껴진다.
제안 : 아주 강력한 고스트타입 포켓몬의 기운이 느껴진다.
```

무엇이 좋아졌나. `En concreto`는 스페인어에서 앞 문장을 좁혀 받는 연결사인데, 한국어에서 「구체적
으로는」은 논설문 어투라 게임 지문에 뜨는 순간 번역기 냄새가 난다. 앞 문장(「강한 기운이
느껴진다」)이 이미 있으므로 연결 기능도 문맥이 대신한다. 「매우」→「아주」까지 함께 손봐 문어체를
한 단계 낮췄다 — 16개 타입이 「구체적으로는/구체적으로 말하면/특히/조금 더 느껴보니」로 갈려
있던 것도 이 참에 사라진다.

**S2-b. 「~하는 것은 ~합니다」 명사구 사슬 해체 — uniq 18, rows 19.**
S1의 첫 사례가 여기 겹친다. `것은`→`건`, `1마리`→`하나`, `상태로`→`채로`,
`계속 진행하는`→`다가가는`. 편집 조각 집계에서 `'것은'→'건'` 14회, `'1마리'→'하나'` 13회,
`'상태'→'채'` 9회, `'계속 진행하'→'다가가'` 7회로 잡힌다.

**S2-c. 괄호 부연 삭제 — uniq 2.** 원문에 있는 괄호 설명을 **일부러 버렸다.**

```
원문 : Los ataques de contacto pueden aplicar Hemorragia (el objetivo tendrá el doble de prob. de recibir golpes críticos).
현재 : 접촉 공격으로 출혈 상태를 만들 수 있다(상대가 급소를 맞을 확률이 2배가 된다).
제안 : 접촉 공격으로 출혈 상태를 만들 수 있다.
```

원문 충실도를 깎고 화면 가독성을 택한 판단이다. 특성 설명란은 줄 수가 제한되고, 「출혈」이라는
상태 이름을 이미 아는 플레이어에게 배율 설명은 중복이다. 같은 판단이 도구 설명(uniq 1)에도 있다.

**S2-d. 잉여 수식어·지시사 삭제 — 수작업 열거, 하한 6건.**

| 원문 | 현재 | 제안 |
|---|---|---|
| `¡Castigar a los opresores de la humanidad es clemencia…` | 인류를 억압하는 자들을 처벌하는 것은 | 억압하는 자들을 처벌하는 것은 |
| `…esa <b>cámara secreta</b> del antiguo rey <b>Malvo</b>` | 선왕 말보의 **그** 비밀 방이 | 선왕 말보의 비밀 방이 |
| `…un evento tan importante para la región` | **이 지방의** 중요한 사건에 | 이 중요한 사건에 |
| `…las características asombrosas de los Pokémon` | 포켓몬의 **그** 놀라운 특성을 | 포켓몬의 놀라운 특성을 |
| `Algo huele a chamusquina con monsieur Lanto.` | **큼큼** 구린내가 나 | 구린내가 나 |
| `¿A que son eficaces mis medicinas?` | 제 약이 정말 효과적이지 않나요? | 제 약, 정말 효과적이죠? |

마지막 줄이 특히 문장력 차이다. 스페인어 `¿A que…?`는 동의를 구하는 부가의문인데
「~하지 않나요?」로 옮기면 부정 의문의 무게가 실린다. 「제 약, 정말 효과적이죠?」는 주어를
쉼표로 띄워 구어 리듬을 살리고 어절 수도 줄인다.

### S3. 직역투 해소 — 스페인어 원문과 대조

**S3-a. 관용구를 관용구로 — 수작업 열거 3건(하한).** 확정도: 코퍼스 문자열은 실측,
스페인어 관용구 판독은 추정(사전·용례 지식 기반, 원어 화자 확인 안 함).

```
원문 : No me puedo creer que hayamos bailado al son de la flauta del <b>Team Azoth</b> todo este tiempo.
현재 : 우리가 그동안 <b>팀 아조스</b>의 피리 소리에 맞춰 춤을 춘 꼴이었다니, 정말 믿기지가 않는군.
제안 : 우리가 그동안 <b>팀 아조스</b>의 장단에 놀아나고 있었다니, 정말 믿기지가 않는군.
```

`bailar al son (que le tocan)`은 「남이 타는 가락에 맞춰 춤춘다」, 즉 조종당한다는 스페인어 관용구다.
현재 번역은 낱말을 그대로 옮겨 이미지만 남기고 뜻을 독자에게 재조립시킨다. 한국어에는 「남의
장단에 놀아나다」라는 **구조가 같은 관용구**가 이미 있다 — 제안은 그것으로 갈아 끼웠다.
이미지 손실도 없다(가락·장단이 대응한다).

```
원문 : Por favor, no causes problemas si no quieres sufrir el largo y férreo estoque de la ley.
현재 : 법이라는 서슬 퍼런 장검 맛을 보고 싶지 않다면 문제를 일으키지 마십시오.
제안 : 법의 철퇴를 맛보고 싶지 않다면 문제를 일으키지 않는 게 좋을거다.
```

`el largo y férreo estoque de la ley`(법의 길고 무쇠 같은 레이피어)를 「서슬 퍼런 장검」으로 옮기면
독자가 처음 보는 비유라 한 박자 멈춘다. 한국어의 「법의 철퇴」는 같은 뜻을 굳어진 말로 전달한다.
총사(mosquetero)가 화자이므로 검 이미지를 버리는 손실이 있지만, 유지자는 통용되는 말을 택했다.

```
원문 : Una cosa te voy a decir: dos carabinas tengo.
현재 : 한 가지 말해두자면, 난 카라빈 소총을 두 자루나 갖고 있다네.
제안 : 한마디만 해 두지. 나한텐 총이 두 자루 있다네.
```

`carabina`를 「카라빈 소총」으로 음차하면 무기 고증이 대사의 주제인 것처럼 읽힌다. 이 대사의
핵심은 노인이 무장하고 있다는 사실이므로 「총」으로 충분하다. 앞머리도 「말해두자면」(연결) →
「한마디만 해 두지.」(끊고 시작)로 바뀌어 노인 말투의 뜸 들이는 리듬이 산다.

**S3-b. 어순 재배치 — 수작업 열거 2건(하한).**

```
원문 : \c[6]<b>Mirra:</b>\c[0] Formando una extraña pareja, está <i>monsieur</i> <b>Lanto</b>.
현재 : <b>미라:</b> 기묘한 짝을 이루는 인물로는 <i>무슈</i> <b>란토</b>가 있다.
제안 : <b>미라:</b> <i>무슈</i> <b>란토</b>는 그자와 기묘한 짝을 이루고 있다.
```

스페인어는 현재분사구를 앞세우고 주어를 뒤로 뺄 수 있다(`Formando…, está Lanto`). 현재 번역은
그 구조를 그대로 살려 「~하는 인물로는 X가 있다」는 명단 낭독 어투가 됐다. 미라가 적 간부들을
하나씩 짚어 주는 장면이라 **주어를 앞세우는 한국어 어순**이 맞다. 제안은 「란토는 ~하고 있다」로
돌려놓으면서 앞 문장의 인물을 「그자와」로 명시해 문단 연결까지 살렸다.

```
원문 : Aunque tenerlos delante sería inútil salvo para postrarse ante su poder elemental, pues su furia puede llegar a ser terrible.
현재 : 하지만 놈들의 분노는 끔찍해서, 막상 맞닥뜨려 봤자 그 원초적인 힘 앞에 무릎 꿇는 것 말고는 할 수 있는 게 없을 거다.
제안 : 뭐, 실제로 마주친다면 그 압도적인 힘 앞에 엎드리는 것 말고는 아무것도 할 수 없겠지만. 놈들의 분노는 무시무시하거든.
```

여기서는 반대로 **원문의 순서를 지켰다.** 스페인어는 양보절을 먼저 놓고 `pues`(왜냐하면)로 이유를
덧붙인다. 현재 번역은 「이유가 먼저, 결과가 나중」이라는 한국어 기본형으로 뒤집었는데, 그러면
말꼬리를 흐리며 덧붙이는 사냥꾼의 말투가 사라진다. 제안은 한국어에도 있는 **후치 이유 어미
「~거든」**을 써서 원문 순서를 유지한다 — 어순을 뒤집는 게 늘 정답이 아니라, 한국어에 같은
기능의 장치가 있으면 그것을 쓴다는 판단이다.

**S3-c. 다의어를 사전 첫 뜻으로 옮긴 오역 — uniq 5, rows 122.**
문장력이라기보다 도메인 오역이지만, 결과물은 전형적인 직역투로 읽히므로 여기 둔다.

| 원문 | 현재(사전 첫 뜻) | 제안(게임 맥락) | rows |
|---|---|---|---|
| `Exportar equipo` | 장비 수출 | 쇼다운 파일로 내보내기 | 30 |
| `Recordar movimiento` | 동작 기억하기 | 기술 떠올리기 | 31 |
| `Niveles de los líderes` | 리더의 수준 | 섭정들의 레벨 | 30 |
| `Crecer` / `Decrecer` | 자라다 / 축소하다 | 키운다 / 줄인다 | 2 |
| `El de tipo Planta` | ‘플란타’ 유형 | 풀 속성 | 1 |

`equipo`는 팀·엔트리인데 「장비」로, `movimiento`는 포켓몬 기술인데 「동작」으로, `nivel`은
레벨인데 「수준」으로 갔다. `Crecer/Decrecer`는 UI 버튼이라 명령형 「키운다/줄인다」여야 하는데
사전형 「자라다/축소하다」로 놓였다. `tipo Planta`는 아예 번역되지 않고 「‘플란타’ 유형」으로
음차됐다. **공통점은 전부 UI 단어이고, 문맥 없이 한 낱말씩 번역했을 때 나는 사고다.**

**S3-d. 외국어 잔존을 한글로 — uniq 9, rows 10 (실측).**
재현: `count2.py`의 「I 로마자 잔존 한글화」 블록.

```
원문 : Gracias al manuscrito hallado en <i>Chateau</i> <b>Rosillon</b>, …
현재 : <i>Chateau</i> <b>Rosillon</b>에서 발견한 원고 덕분에 …
제안 : <b>로시욘 저택</b>에서 발견한 원고 덕분에 …
```

이 게임은 프랑스풍 세계관이라 스페인어 원문 안에 프랑스어가 이탤릭으로 섞여 있다
(`folie`, `s'il vous plait`, `du diable`, `style`, `Chateau`). 유지자의 처리는 **일률적이지 않고
둘로 갈린다.**

- **분위기 장치인 감탄사·인사는 원문 그대로 둔다**: `Putain!`, `Sacrebleu!`, `Voilà!`,
  `Mon Dieu!`, `Oui!`, `C'est incroyable!`, `무슈`, `마담`, `마드모아젤`은 제안에서도 남아 있다.
- **뜻을 몰라 문장이 안 읽히는 것은 한글로 옮긴다**: `folie`(광기) → 「황당한 짓」,
  `s'il vous plait` → 「부디」 또는 「당장」, `style` → 「스타일」, `Chateau Rosillon` → 「로시욘 저택」.

```
원문 : Tú no te unirás a esta completa <i>folie</i>, ¿no, \PN? ¡Tienes más sensatez!
현재 : 너는 이런 완전한 <i>folie</i>에 동참하지 않을 거지, \PN? 너는 더 사리 분별이 있잖아!
제안 : \PN, 너까지 이 황당한 짓에 끼어들 건 아니지? 넌 그래도 분별력이 있잖아!
```

한 문장 안에 네 가지가 겹쳐 있다. `folie`를 「황당한 짓」으로 풀었고, 호격 `\PN`을 문두로 올렸고
(스페인어는 부가의문 앞에 붙지만 한국어는 문두 호격이 자연스럽다), `esta completa folie`의
`completa`(완전한)를 버렸으며(「완전한 광기」는 번역투), `Tienes más sensatez`의 비교급을
「더 사리 분별이 있잖아」(무엇보다 더?)에서 「그래도 분별력이 있잖아」로 바꿔 비교 대상을
문맥에 맡겼다.

스페인어 도치 문장부호 `¡ ¿`가 한국어 문안에 남아 있던 것도 3건 지웠다.

### S4. 시리즈 정본 문구로 교체 — uniq 8, rows 37 (실측)

유지자 코멘트가 이 판단을 직접 말한다 — **「본가 표현으로. 비슷한 것들 모아서」**
(코퍼스 L340, 분류 23:시스템 문구).

```
원문 : ¡Pero no tuvo ningún efecto!      /  No tuvo ningún efecto.  /  No tendrá ningún efecto.
현재 : 하지만 아무 효과도 없었다!         /  아무 효과도 없었다.      /  아무런 효과도 없다.
제안 : 그러나 아무 일도 일어나지 않았다!  (셋 다 같은 문안으로)
```

원문을 그대로 옮기면 「아무 효과도 없었다」가 맞다. 그런데 포켓몬 본가 한국어판은 같은 상황에서
**「그러나 아무 일도 일어나지 않았다!」**라는 굳어진 문구를 쓴다. 유지자는 원문 충실도보다
시리즈 플레이어의 기대를 택했다. 「튀어오르기」 기술 설명에서도 같은 판단이 반복된다
(`No tiene ningún efecto. Solo salpica.` → 「튀어오르기! 그러나 아무 일도 일어나지 않았다!」).

같은 유형에서 행 수가 가장 큰 것은 아이템 획득 문구다 — **「발견했다」→「얻었다」 21건(실측,
편집 조각 집계에서 최다 2위)**. 스페인어 `ha encontrado`/영어 `found`는 문자 그대로 「발견했다」
지만 본가 한국어판은 「얻었다」다.

### S5. 감탄사·의성어 현지화 — uniq 6~7 (실측, D 블록 6건 + L0)

**포켓몬 울음소리는 한국어 종명에서 다시 만든다.**

```
원문 : <b>Morelull:</b> Luuuuull...        원문 : <b>Floette:</b> ¡Floo! ¡Flooo!
현재 : <b>자마슈:</b> 루우우울...            현재 : <b>플라엣테:</b> 플루! 플루우!
제안 : <b>자마슈:</b> 자마아...              제안 : <b>플라엣테:</b> 플라! 플라아!
```

원문의 울음은 스페인어 종명(Morelull, Floette)의 꼬리를 늘인 것이다. 한국어 종명은 자마슈·
플라엣테이므로 **같은 규칙을 한국어 이름에 다시 적용해야** 「이 포켓몬이 자기 이름으로 운다」는
장치가 살아난다. 「루우우울」은 한국 플레이어에게 아무 이름도 환기하지 않는다.

**웃음소리는 한국어 관용 웃음으로.** `Jue, jue, jue!`(야느와르몽) → 「훠, 훠, 훠!」 → **「히, 히, 히!」**,
`Je, je, je!`(마부) → 「헤헤헤!」 → **「하하하!」**. 스페인어 `j`는 [x] 음이라 음차하면 「훠/헤」가
되는데, 한국어에서 「훠훠훠」는 웃음으로 읽히지 않는다. 유령 포켓몬은 음산한 「히히히」, 호탕한
마부는 「하하하」로 **인물 성격에 맞춰 갈랐다.**

**가장 극적인 사례(코퍼스 첫 행, L0).**

```
원문 : \sh¡TAAAAAAAAL!
현재 : \sh그랬지!!!!
제안 : \sh키아아아아아!
```

현재 번역은 `TAAAAAAAAL`을 스페인어 부사 `tal`(그러한)의 늘임으로 읽고 「그랬지」로 옮겼다.
그러나 이 대사가 서는 자리는 맵 408 「Pesadilla del Circo」(서커스의 악몽)의 컷신이고, `\sh`는
화면 흔들림 지시자다. 즉 **비명이지 낱말이 아니다.** 제안은 비명 「키아아아아아!」로 되돌린다.
문법적으로 그럴듯한 낱말을 찾아낸 것이 오히려 오역이 된 경우다.

### S6. UI 확인 프롬프트의 2인칭 직역 — uniq 6, rows 47 (실측: 18+11+2+…)

**규칙화 가치가 가장 큰 발견이다.** 스페인어 `¿Quieres …?`는 게임의 예/아니오 확인창 문구인데,
글자대로 옮기면 「~하고 싶니?」가 되어 **NPC가 플레이어에게 묻는 말**로 읽힌다. 한국어 게임의
확인창 관례는 **플레이어 자신의 자문 「~할까?」**다.

| 원문 | 현재 (2인칭 직역) | 제안 (자문형) | rows |
|---|---|---|---|
| `¿Quieres hacerlo salir?` | 그걸 꺼내고 싶니? | 다가가 볼까? | 18 |
| `¿Quieres abrir la puerta?` | 문을 열어줄래? | 잠긴 문을 열까? | 1 |
| `¿Qué quieres hacer?` | 뭘 하고 싶니? | 어떻게 할까요? | 1 |
| `Acepto` | 동의합니다 | 그렇게 하죠 | 11 |
| `Me parece muy bien` | 정말 좋네요 | 그렇게 하죠 | 1 |
| `¿Y quién no lo haría?` | 누가 안 그러겠어? | 밸브를 돌렸다! | 2 |

`¿Quieres abrir la puerta?`가 특히 선명하다. 「문을 열어줄래?」는 **부탁**이고 「잠긴 문을 열까?」는
**자문**이다. 원문은 자물쇠 앞에서 뜨는 확인창이므로 후자가 맞다. 제안은 「잠긴」까지 더해
어느 문인지도 밝힌다.

`Acepto`(동의한다) 11건은 선택지 버튼이다. 「동의합니다」는 약관 화면 같고, 「그렇게 하죠」는
대화 선택지로 읽힌다. 원문에는 없던 화자 태도가 들어가지만 자리에 맞는다.

마지막 줄에는 유지자의 코멘트가 붙어 있다 — **「어떻게 옮겨도 부자연스러워 의역함」**(L589).
`¿Y quién no lo haría?`(누군들 안 그러겠는가?)는 밸브를 돌린 뒤 뜨는 문구인데, 한국어로
직역하면 무엇에 관한 반문인지 알 수 없다. 제안은 **원문을 버리고 화면에서 실제로 일어난 일**
(「밸브를 돌렸다!」)을 적었다. 원문 이탈의 가장 강한 사례다.

### S7. 정보를 더하거나 빼는 재작성

**S7-a. 구문 오독을 복원 — 수작업 열거, 하한 3건.**

```
원문 : Los componentes … han permitido crear un suero que acaba con la vida del Pokémon, pero genera <i>energía vital</i> durante el proceso.
현재 : 늪지에서 가져온 부품들로 포켓몬의 목숨을 앗아가는 혈청을 만들 수 있었지만, 그 과정에서 <i>생명 에너지</i>가 생성됩니다.
제안 : 늪지대에서 가져온 성분을 이용해 포켓몬의 생명을 앗아 가는 한편, 그 과정에서 <i>생명 에너지</i>를 생성하는 혈청을 만들어 냈다.
```

원문에서 `pero genera…`는 **관계절 `que` 안에 있다** — 혈청이 하는 일이 둘(생명을 앗음 + 에너지를
생성)이라는 뜻이다. 현재 번역은 `pero`를 주절의 역접으로 끌어내 「혈청을 만들 수 있었지만,
(그런데) 에너지가 생성됩니다」가 됐다 — 부작용을 말하는 문장처럼 읽힌다. 제안은 관계절을
복원해 두 기능을 나란히 놓는다. **의미가 뒤집히는 오역을 문체 손질처럼 보이는 재작성으로 고친 것.**

```
원문 : \c[2]<b>Olivier:</b>\c[0] ¿Qué fue lo que descubriste y por qué el <b>Team Azoth</b> lo anhela tanto?
현재 : 네가 도대체 무엇을 발견한 거지? 그리고 <b>팀 아조스</b>는 왜 그것을 그토록 원하는 걸까?
제안 : 스승님께선 도대체 무엇을 발견하신 거지? 그리고 …
```

스페인어 2인칭 `descubriste`가 누구를 가리키는지 화면 앞 인물이 아니라 **부재중인 스승**이다
(올리비에가 혼잣말로 스승에게 묻는 장면). 현재 번역은 「네가」로 놓아 대화 상대를 향한 추궁이
됐다. 같은 유형으로 `Necesitamos que sea partícipe` → 「그 녀석도」 → **「멜리아도」**(대명사를
고유명사로 밝힘)가 있다.

**S7-b. 원문에 없는 정보를 더함 — 수작업 열거, 하한 2건.**

```
원문 : No puedes viajar aquí.
현재 : 여기로는 이동할 수 없다.
제안 : 여기서는 공중날기를 할 수 없다.
```

`viajar`(이동하다)만 있는 원문에 **기술명 「공중날기」를 넣었다.** 이 문구가 뜨는 곳은 공중날기
지도이므로, 「이동할 수 없다」는 걸어서도 못 간다는 오해를 부른다. 같은 판단이 `Exportar equipo`
→ 「쇼다운 파일로 내보내기」에도 있다(무엇으로 내보내는지 원문에 없는 정보를 채웠다). 다만 이
항목은 유지자 본인이 3단계에 걸쳐 고쳤다 — 「엔트리 복사하기」 → 「엔트리 내보내기」 →
「엔트리 내보내기(쇼다운 파일 생성)」 → 「쇼다운 파일로 내보내기」. 마지막이 가장 짧으면서
정보량은 같다.

### S8. 존대 층위 조정 — uniq 85 (내림 65 / 올림 20), rows 86 (실측)

제안 : 새로운 포켓몬 연금술 페이지를 찾았다! 정말 신난다!

(`otra`의 직역 회피)도 함께 손봤다.

또 하나, **문말만 손댄 재작성이 uniq 122건**(전체 616건의 20%)이다. 재현: `count3.py`의

가장 흔한 단일 동작이다.

## 2. LLM 배치 재번역 프롬프트에 실을 규칙 후보

일반화 가능성이 높은 순서. 각 규칙 뒤에 근거 유형과 코퍼스 근거 규모를 적었다.

### 강한 규칙 — 기계적으로 적용 가능

**R1. UI 확인·선택 문구는 2인칭으로 옮기지 마라.** (근거 S6, rows 47)
스페인어 `¿Quieres …?` / `¿Qué quieres hacer?`가 확인창·선택지 자리에 있으면 「~하고 싶니?」가
아니라 플레이어 자문 **「~할까?」**로 옮긴다. `Acepto` 같은 선택지 버튼은 「동의합니다」 같은
문서 어투가 아니라 대화체 「그렇게 하죠」로.

**R2. 시리즈 정본 문구가 있는 상황은 원문 직역보다 정본을 따른다.** (근거 S4, rows 37 + 유지자
코멘트 「본가 표현으로」)
프롬프트에 대응표를 실어라 — `no tuvo ningún efecto` → 「그러나 아무 일도 일어나지 않았다!」,
`ha encontrado`/`found`(아이템) → 「얻었다」(「발견했다」 금지), `recordar movimiento` →
「기술 떠올리기」, `tipo <속성>` → 「<속성>타입」.

**R3. 포켓몬 울음소리는 스페인어 종명이 아니라 한국어 종명에서 만든다.** (근거 S5)
`Luuuull`(Morelull) → 「자마아」(자마슈), `Floo`(Floette) → 「플라」. 웃음소리는 음차하지 말고
한국어 관용 웃음으로 옮기되 인물 성격에 맞춘다(유령 「히히히」, 호탕한 노인 「하하하」).

**R4. 문두 연결 부사구를 직역해 붙이지 마라.** (근거 S2-a, rows 16)
`En concreto,` / `De hecho,` / `Por lo visto,` 류를 「구체적으로는」·「사실상」·「들리는 말로는」으로
옮기면 논설문 어투가 된다. 앞 문장이 있으면 지우고, 필요하면 어미로 흡수한다.

**R5. UI 단어는 사전 첫 뜻이 아니라 게임 맥락으로 옮긴다.** (근거 S3-c, rows 122)
`equipo`=엔트리/팀(장비 아님), `movimiento`=기술(동작 아님), `nivel`=레벨(수준 아님),
`líder`=관장/섭정(리더 아님), `tipo`=타입/속성(유형 아님). 버튼·메뉴 항목은 명령형으로
(`Crecer` → 「키운다」, 「자라다」 금지).

**R6. 같은 원문에는 같은 번역을 준다.** (근거 S1, rows 75)
배치 재번역이면 원문을 키로 묶어 한 번만 번역하고 전 자리에 같은 값을 쓴다. 자리마다 따로
번역시키면 「나무열매 관목」이 12종으로 갈라진다 — 이 코퍼스의 실측이다.

### 중간 규칙 — 판단이 필요하지만 지시 가능

**R7. 관용구는 관용구로 갈아 끼운다.** (근거 S3-a, 3건)
낱말을 옮겨 이미지만 남기지 마라. 스페인어 관용구를 만나면 뜻이 같은 한국어 관용구를 먼저
찾는다(`bailar al son de` → 「장단에 놀아나다」, `el estoque de la ley` → 「법의 철퇴」).
없을 때만 풀어 쓴다.

**R8. 명사구 사슬을 어미로 푼다.** (근거 S2-b, rows 19)
「~하는 것은 ~합니다」 → 「~는 건 ~하다」. 「~한 상태로」 → 「~한 채로」. 「1마리」 →
(수를 세지 않는 맥락이면) 「하나」.

**R9. 지시사·잉여 수식어를 지운다.** (근거 S2-d, 하한 6건)
스페인어 `ese/esta`가 한정 기능만 할 때 「그/이」를 붙이지 않는다. `completo`, `mismo`,
`realmente` 류 강조어는 한국어에서 뜨면 지운다.

**R10. 화면 자리를 알 수 없으면 원문에 없는 정보를 넣지 말되, 알면 넣어라.** (근거 S7-b)
「여기로는 이동할 수 없다」보다 「여기서는 공중날기를 할 수 없다」가 낫다. 배치 프롬프트에
자리 정보(맵·이벤트·프롬프트 여부)를 함께 넘길 수 있다면 이 규칙이 살아난다 — 코퍼스의
조인 필드(`scene`, `prompt`, `who`)가 이미 그 정보를 갖고 있다.

**R11. 원문 안의 프랑스어는 두 갈래로 나눈다.** (근거 S3-d, 9건)
감탄사·호칭(`Putain!`, `Sacrebleu!`, `monsieur`, `madame`)은 남겨 분위기를 살리고,
뜻을 모르면 문장이 안 읽히는 명사·구(`folie`, `s'il vous plait`, `Chateau <지명>`)는 한글로 옮긴다.
스페인어 도치 문장부호 `¡ ¿`는 한국어 문안에 남기지 않는다.

**R12. 관계절의 범위를 확인하고 옮긴다.** (근거 S7-a)
`que … , pero …` 구조에서 `pero`가 관계절 안인지 주절인지 갈리면 의미가 뒤집힌다.
2인칭 동사 어미(`descubriste`)의 지시 대상도 대화 상대가 아닐 수 있으니 장면으로 확인한다.

### 약한 규칙 — 방향만 제시

**R13. 짧아지는 쪽을 택한다.** (근거: 904행 중 짧아진 것 399 vs 길어진 것 246)
같은 뜻으로 두 문안이 가능하면 짧은 쪽. 다만 R10과 충돌할 수 있으므로 정보 손실이 없을 때만.

**R14. 원문을 도저히 자연스럽게 옮길 수 없으면 화면에서 실제로 일어난 일을 적어라.**
(근거 S6 마지막 줄 + 유지자 코멘트 「어떻게 옮겨도 부자연스러워 의역함」)
배치 작업에서는 위험한 규칙이라 **자동 적용 금지, 사람 검토 대상으로 표시**하는 쪽이 맞다.

## 3. 한계 — 하지 못한 것과 불확실한 것

- **유형 분류는 내 판독이다.** 616건을 전수로 읽고 매겼지만, 정규식으로 못 세는 유형
  (관용구 교체·어순 재배치·잉여 수식어)은 **수작업 열거라 하한값**이다. 놓친 사례가 있을 수 있다.
- **스페인어 관용구 판독은 추정이다.** `bailar al son de la flauta`, `el estoque de la ley`,
  `¿A que…?`의 뜻풀이는 사전·용례 지식에 기댄 것이고 **원어 화자나 사전 원문으로 확인하지
  않았다.** 코퍼스에 실린 문자열 자체는 실측.
- **「제안이 더 낫다」는 판정은 문안 대조에 근거한 것이지 플레이 화면 확인이 아니다.**
  `\sh`가 화면 흔들림 지시자라는 것, `¿Quieres…?`가 확인창에 뜬다는 것은 코퍼스의 `prompt`·
  `scene` 필드와 문맥에서 읽은 것이지 게임을 실행해 본 것이 아니다.
- **유지자 제안이 실제로 반영됐는지는 갈린다.** `반영상태` 필드에 「제3값」(제보 뒤 다른 판정이
  지나감)이 상당수 있다. 즉 **여기 적은 제안 전부가 현행 정본은 아니다.** 규칙을 뽑을 때는
  「유지자가 그렇게 고치려 했다」까지가 근거이고, 「그게 최종 정본이다」는 별도 확인이 필요하다.
- **S8(존대 층위)은 렌즈 3과 겹친다.** rows로는 크지만 문체 축 고유의 발견은 「화자 없는 지문의
  평서형화」 하나뿐이다. 렌즈 3의 결과와 대조해 중복을 정리해야 한다.
- **S3-c(다의어 오역)는 렌즈 1과 겹친다.** rows 122로 커 보이지만 UI 항목 5종이 자리 30곳씩
  차지한 결과이고, 판단 자체는 5건이다.
