# Z-49 — Controller UX 엑스박스판 (유저 「키 변경」 흡수)

발단: 디시 갤러리 유저의 「키 변경」(2026-08-11 배포) — 조작을 패드 배열로 옮기는 모드.
우리 `Controller UX`와 같은 자리를 건드려 그대로는 못 얹는다.

⚠ **처음 적었던 배선 표가 뒤집혀 있었다.** 정정본은
[패드 기본 배치 조사](../log/research/2026-08-13-pad-default-bindings.md)가 정본이다.
기본 F1이 이미 아래 버튼 확인 · 오른쪽 버튼 취소라, 확인·취소를 맞바꾸는 판정은
철회했다. 아래 「무엇을」은 그 정정 뒤의 것이다.

## 한 일 (poke-essentials `a0dc20e`)

모드 소스의 정본은 poke-essentials `mod/z/mods/Controller UX/`다. 파일을 여섯으로
다시 갈랐고 판을 1.0으로 올렸다.

- `000_PadDetect` — `Input.joystick`으로 패드 유무를 주기로 잰다. 확장이 없는 판본이면
  「있다」로 본다.
- `002_Cursor` · `004_TextEntryPad` — 내용 그대로, 번호만 옮겼다.
- `003_FieldPad` — 등록 도구(가상 X)를 `Scene_Map#update` 별칭이 아니라
  `Events.onMapUpdate`로 옮겼다. 그 훅은 입력 분기보다 앞에서 돌아 깃발만 세우면
  원작이 이어받는다.
- `005_PadLabels` — 패드가 없으면 라벨을 갈아 끼우지 않는다.
- 가방 그림 16장 — 「LB: 정렬 / RB: 검색」으로 새로 그렸다. 만드는 법은
  `tools/make_bag_labels.py`(원본 글꼴 규칙으로 `D`를 재현해 검증한 뒤에만 쓴다).

구문은 게임 실행기(루비 1.8.7)로 여섯 파일 전부 확인했고, modkit `lint` 통과,
설치본에 얹었다.

## 하지 않은 것과 그 까닭

- **화면 단위 입력 치환기를 만들지 않았다.** 유저가 복사한 세 파일에서 바뀐 열 줄은
  전부 **그 사람이 F1을 다시 잡은 배치**에 맞춘 것이다. 기본 배치에서 그 화면들의
  기능은 이미 패드로 닿는다(가방 정렬 LB · 검색 RB · 자리 바꾸기 Y버튼, 일시정지
  메뉴 회복 X · 이동 LB · 나침반 RB, 대사 빨리감기 Y버튼). 치환할 것이 없다.
- **패드로 못 닿던 자리는 둘뿐이었고 둘 다 이미 메워져 있었다** — 등록 도구(가상 F5는
  패드 배정이 없다)와 이름 입력 완료(키보드 Return 직독). 각각 `003_FieldPad`와
  `004_TextEntryPad`가 맡는다.
- **권장 F1 배치표를 문서로 내지 않는다.** 모드 안내문에만 적는다 — 그리고 그 안내문은
  이제 「F1은 손대지 않아도 된다」고 말한다.
- **`%APPDATA%`의 배치 파일을 설치기가 쓰지 않는다** — 남이 F1에서 만든 배치를 덮는다.

## 되돌린 것 — 배속은 오른쪽 스틱에 그대로 둔다

가상 L(오른쪽 스틱 클릭)에서 배속을 떼는 `001_TurboNoL`을 넣었다가 뺐다. 원작 조건의
다른 한쪽인 `Input::ALT`가 키보드 전용이라, L을 떼면 **패드로는 배속을 걸 길이
없어진다**(유지자 지적 2026-08-13). 대안 자리도 없다 — 근거는
[패드 기본 배치 조사](../log/research/2026-08-13-pad-default-bindings.md).

## 남은 것

실기 확인뿐이다 — 필드에서 X로 등록 도구, 이름 입력, 가방 그림 표기, 패드를 뺐을 때
라벨이 키보드 표기로 돌아가는지.

## 알아 둘 것 — 배치는 모드가 못 바꾼다

물리 버튼과 가상 버튼의 짝은 실행기 F1 메뉴가 정하고 게임 폴더 밖
(`%APPDATA%\<제목>\keybindings.mkxp1`)에 저장된다. 모드는 읽지도 쓰지도 못한다.
패드 종류(`Input.joystick[:name]`)는 라벨 표기에만 쓸 수 있다 — 구판은 원시 버튼
번호로만 묶어서 종류를 알아도 배치를 못 고친다.

⚠ **가상 L·R은 새로 쓰지 않는다** — 엑스박스에서 오른쪽 스틱 클릭과 가이드 버튼에
떨어지고, 가이드는 OS·스팀이 가로챈다.
