# Z-61 — 전이 뒤 대사가 원문으로 뜨던 자리

**단계** P-2(가능성 확인) → 닫음 · **크기** 중간

유지자 제보 넷(「대등한 조건에서 겨뤄볼…」·「그 권리를 포기할 셈인가?」·「페로파스의
소식을…」·「이제 네 감방으로 돌아갈 시간이다」)이 실기에서 스페인어로 나오던 자리.
원인·규모는 [2026-08-16 조사](research/2026-08-16-transfer-then-text.md).

## 고친 방식 — 맵0 전역 폴백에 얹는다

조사는 「도착 맵마다 정본 줄을 얹는다」를 유력한 길로 봤으나, 게임의 조회 사슬을
다시 읽어 **더 좁은 길**을 찾았다. `Intl_Messages:572-584`:

```ruby
def getFromMapHash(type,key)      # type = 현재 맵 id
  id = Messages.stringToKey(key)
  if @messages[0][type] && @messages[0][type][id]
    return @messages[0][type][id]           # ① 현재 맵
  elsif @messages[0][0] && @messages[0][0][id]
    return @messages[0][0][id]              # ② 맵0 전역 폴백
  end
  return key                                # ③ 원문 그대로
end
```

맵0은 상류가 **공통 이벤트 대사를 넣는 칸**이고(같은 파일 37-40·98행이
`Data/CommonEvents`를 읽어 id 0으로 등록, 590행 주석 「Value 0 is used for common
event and map event text」), 손 안 댄 상류 원본 `messages.dat`에도 키 70개가 들어
있다. 우리가 만든 칸이 아니다.

여기 얹으면 도착 맵이 무엇이든 ②에서 잡힌다. ①이 먼저 이기므로 맵별 번역을 덮지도
않는다. 조건 분기를 자리마다 갈라내는 일(옛 할 일 3)과 공통 이벤트 층 조사(옛 할 일 4)가
함께 필요 없어졌다 — 어느 맵에서 조회되든 같은 칸이 받는다.

## 안전 근거

- **충돌 0건** — 후보 67행의 원문은 전부 번역이 하나뿐이다(맵마다 갈리는 것 0건).
  둘은 이미 맵0에 있어 건너뛰었고, 남은 65행이 원문 기준 **37가지**다.
- **기존 값 무변경** — 빌드가 「정본과 dat의 값 차이 0곳, 새 키 추가 37개」.
- **재빌드 안전** — 꼬리가 붙은 dat를 입력 삼아 다시 빌드하면 「새 키 추가 0개」.
  2026-08-09에 한 번 났던 「제 산출물로 두 번째 빌드가 죽는」 사고를 같은 자리에서 막았다.
- **루비 실물 대조** — 포터블 루비 3.4.5로 게임의 `OrderedHash`·`Messages` 정의를
  스크립트에서 줄째 잘라 그대로 돌렸다. 시험판에서 `getFromMapHash(3, "¿Vas a negarte
  ese derecho?")`가 「그 권리를 포기할 셈인가?」를 반환하고, 손 안 댄 대조군에서는
  스페인어 원문이 그대로 나온다. 맵 508개 전부 예외 없이 로드되고 전체 키 수는
  13,770 → 13,807로 증가분이 맵0 증가분과 정확히 일치한다.
- 빌드 뒤 dat 실물에서 추가분 37줄의 값이 전부 맞는 것을 확인했다(불일치 0건).

미확인 하나 — **게임 화면에 뜨는 것은 아직 못 봤다.** 유지자가 이미 지나온 자리들이라
불러올 수 없다. 확인은 앞으로의 진행에서 자연히 되거나 Z-45(장면 이동)가 서면 된다.

### 덧붙임 (같은 날 늦게) — 루비 1.8.7로 다시 재서 판 차이 걱정을 닫았다

위에 「이 시험이 말하지 않는 자리」로 남겨 둔 루비 판 차이를 1.8.7 실물
(도커 `ollijh/ruby1.8:stretch-slim`, p376)로 다시 쟀다. **출력이 3.4.5와 한 글자도 다르지
않다** — 맵 508개 전부 예외 없이 로드, 맵0 키 107개, 전체 키 13,807개, 꼬리 표제가 조회에
걸려 한글 반환. 걱정하던 UTF-8 딱지 사고도 1.8.7에서 안 났다(딱지가 바이트열로 무해하게
지나간 것으로 **추정**하되 관측은 「사고가 안 났다」까지다).

대조군은 배포본 v5.3(`share/dist/…`, 맵0 키 70개)으로 바꿔 세웠다 — 게임 설치본은 이미
빌드가 들어가 대조군 노릇을 못 한다. 남는 미확인은 RGSS 내장 루비가 1.8.7이 아니라 통상
1.8.1이라는 점인데, 1.8.1에만 다른 동작이 있다는 근거는 못 찾았다(**침묵이지 부정이 아니다**).

## 도구가 바뀐 것

`build.py`가 맵 절에도 추가분을 받는다. 해시 절이 쓰던 꼴을 그대로 옮겼고
(꼬리 허용 + 정본에 접힌 키는 정본이 이김), 덧붙이는 부분은 두 절이 같은 일을 하므로
함수 하나로 묶었다. 정본 파일은 `translate/ko/00-maps.add.jsonl` — 줄마다 어느 맵에
붙는지를 `map`으로 들고 다닌다.

## 곁들여 나온 것

**미번역이 눈에 안 띄는 이유가 밝혀졌다.** `UI Text KR` 모드가
`Window_AdvancedTextPokemon#setText`를 alias로 감싸 화면에 뜨는 모든 문자열에 인물
이름 24개를 gsub한다. 번역 조회는 그보다 앞에서 끝나므로, **조회가 실패해도 이름만
한글로 보인다.** 이 무리 67행 중 넷이 그 꼴이었다(페로파스 하나·올리비에 셋).
게임 자체에는 NPC 이름 치환 층이 없고(`\PN`·`\N[n]`뿐), `patch_intl.py`의 수술
아홉 묶음에도 이름을 건드리는 것이 없다.
