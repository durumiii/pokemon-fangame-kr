# Z-32 — 신형 루비 지뢰 선제 제거

근거: [2026-08-09 호환 감사](../log/research/2026-08-09-ruby-compat-sweep.md).
배포 코어 260개 섹션을 전수 감사해 나온 지뢰 목록을, 밟히기 전에 없앤다.
감사 도구는 `share/qa-ruby-compat.py` — 코어를 새로 구울 때마다 다시 돌리면 된다.
Runa가 mkxp-z(루비 3.1 기본) 기반으로 확인돼(웹, Z-31 참조) 이 목록은 이론 대비가
아니라 **현역 모바일 유저가 밟는 지뢰밭**이다 — 몬스터볼 제보의 유력 원인도 이 중
하나(nitems)다.

## 방안 (유지자 판정 대기)

**① 호환 심 한 섹션** — 코어 맨 앞에 「없을 때만 채워 넣는」 심을 얹는다.
없는 API를 되살리는 것이라 1.8.7 실기에는 한 줄도 안 걸린다:

```ruby
# 1.8 API를 신형 루비에, 신형 API를 옛 실행기에 — 없을 때만
class Array; def nitems; count { |x| !x.nil? }; end; end if ![].respond_to?(:nitems)
def File.exists?(p); exist?(p); end if !File.respond_to?(:exists?)
def Thread.critical; false; end if !Thread.respond_to?(:critical)
def Thread.critical=(v); v; end if !Thread.respond_to?(:critical=)
Fixnum = Integer if !defined?(Fixnum)
Bignum = Integer if !defined?(Bignum)
class String; def getbyte(i); unpack("C*")[i]; end; end if !"".respond_to?(:getbyte)
```

즉사형 대부분(nitems·Thread.critical·File.exists?·Fixnum)과 모바일 실행기의
getbyte 부재까지 이 한 장이 덮는다. (문법은 1.8.7로 맞춘다 — `unless` 수식도
되지만 위 꼴이 안전.)

**② 문법 불통 2곳 소스 수술** — 심으로 못 덮는다. 코어 재굽기 때 함께:
- `AudioUtilities` `when 0:` → `when 0 then` (기계 치환)
- `PScreen_Load`의 rescue 밖 `retry` → 루프 재구성 (손수술, 한 자리)

**③ 조용한 오판형은 건드리지 않는다** — BOM 벗기기·GIF 서명 등은 어긋나도
표시가 조금 어긋날 뿐이고, 고치려면 자리마다 의미 검토가 필요하다. 제보가
가리키면 그때 그 자리만.

## 판정과 이행

**우리가 한다** (유지자, 2026-08-09) — 배포 경로가 이 레포이고, 원작 쪽으로
핸드오프하는 비용이 더 크다. 심 + 문법 수술을 한 번에 간다.

**이행 완료 (2026-08-09, 실측)** — 심은 별도 모드가 아니라 코어 맨 앞 섹션
「Z-32 Ruby Compat」으로 넣었다(코어 모드는 `install: assets`라 스크립트 주입 틀이
없고, 코어 자체가 우리 배포물이라 그 안이 가장 확실하다).

- `share/ruby-compat.rb`(심 소스 정본) + `share/patch_ruby_compat.py`(코어 반영,
  멱등) 신설. 보관소 기반판·PC 설치본 양쪽에 적용 완료 — 심 삽입 + AudioUtilities
  콜론 23곳 + PScreen_Load retry 1곳.
- 검증: 수술본을 `qa-ruby-compat.py --ruby 3.4.5`로 재감사 → **문법 불통 0**.
  왕복 대조 → 손 안 댄 258개 섹션 소스 무손상, 수술 차이는 설계와 자리까지 일치.
  심 기능은 루비 3.4에서 실행 검증(nitems·File.exists?·Thread.critical·Fixnum·
  getbyte 채움, getbyte 없는 흉내 런타임 포함).
- `retry`→`next`는 동작 보존이다 — `loop do` 블록 안이라 1.8의 블록 retry(반복자
  재시작)와 next가 관측 가능한 동작이 같고, 삭제 확정 갈래는 그 전의 `return`으로
  이미 나간다.

**남은 것** — ① PC(1.8.7)에서 게임 부팅 한 번(심이 걸리는 데 없이 지나가는지 —
유지자 눈 확인이 가장 싸다). ② 모바일 검증은 재배포에 실려야 가능 — 코어 재굽기
(`runa/make-patch-mod.py`)와 합본 재조립은 다음 릴리스와 함께(Z-31과 같은 배).
