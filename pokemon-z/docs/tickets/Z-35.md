# Z-35 — Joiplay 렌더 문제: MAPVIEWMODE=0 모드

레딧 유저가 「Scripts를 고쳐 Joiplay 렌더 문제를 잡았다」며 배포한 파일에서 유효한
변경은 `Settings`의 `MAPVIEWMODE = 1 → 0`(맵 렌더러를 커스텀에서 원본으로) 한 줄뿐
이다. 배포 파일 자체는 다른 계열(1.55·중국어 혼입) 빌드라 폐기 —
[조사](../log/research/2026-08-09-community-mods-triage.md) ①.

할 일:
- 한 줄을 우리 모드 형식으로 만든다. 주입 섹션에서 상수 재정의 대신
  `PScreen_Options#tilemap`(유일한 사용처)을 덮는 쪽이 깔끔한지부터 본다.
- Joiplay 실기에서 렌더 문제가 실제로 사라지는지, 데스크탑에서 부작용(원본 렌더러로
  바뀌며 화면이 달라지는 것)이 무엇인지 확인 — 개선 주장 자체가 아직 웹1소스다.
- 기본 동봉인지 선택 모드인지 유지자 판정.
