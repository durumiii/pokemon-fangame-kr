# Z-24 — 스크립트에 박힌 한국어 70행: 수술 계획

전수 목록: [script-baked-korean](../log/research/2026-08-08-script-baked-korean.md).
번역표로 못 고치는 자리라 코어의 `Scripts.rxdata`를 직접 수술한다. 아래 계획은
2026-08-09 본가 대조 실측([scout](../log/research/2026-08-09-z21-z24-z30-scout.md))
기반이고, 치환 자구는 유지자 승인 뒤 확정한다.

## 기제

`share/patch_ruby_compat.py`(Z-31) 선례를 그대로 따르는 치환 도구를 만든다.

- 치환은 **절 이름 + 줄 번호 + 기존 문자열 완전 일치**로만 한다 — 하나라도 안 맞으면
  그 항목은 건너뛰고 보고한다(멱등, 추측 치환 없음).
- 치환표는 도구 안이 아니라 별도 JSONL(절·줄·옛 문자열·새 문자열·근거 태그)로 둔다.
- 대상: 보관소 기반판(`/mnt/d/GameVault/.../한글패치 코어/Data/Scripts.rxdata`) +
  설치본. 수술 전 `.pre-baked.bak` 백업(compat 선례와 같음).
- 검증: 수술 후 전수 추출을 다시 돌려 70행이 의도대로 바뀌었는지 대조 +
  `share/qa-ruby-compat.py`로 문법 불통 0 + 비대상 절 무손상 확인.
- 재배포는 Z-31과 같은 코어 재굽기를 타므로 **Z-31 재배포에 합류**한다.
