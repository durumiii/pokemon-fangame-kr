# Z-36 — 상성턱받이 + 디버그 토글을 주입형 모드로

디시 배포판(레쿠쟈 갤 228378)에서 커뮤니티 몫 섹션 셋만 떼어 `MOD:` 주입형으로
이식한다. 배포 파일은 우리 구판 합본 기반이라 통짜 교체 금물 —
[조사](../log/research/2026-08-09-community-mods-triage.md) ②.

- **상성턱받이**(`Bui`, 131줄): 기술 선택창 버튼을 상대 상성 배율로 색칠. alias 없는
  클래스 재정의라 이식 시 현행 방식 유지하되, 배틀 UI를 만지는 다른 모드가 없음은
  확인돼 있다(grep 0건). `MOD:` 이름 규약으로 개명해 `inject.py` 주입.
- **디버그 토글**(`Db` + `디버그 모드/001_HealAfterBattle.rb`): W키로 `$DEBUG` 토글,
  디버그 중 전투 후 전원 회복.

판정·확인 거리:
- `GetAsyncKeyState`(Win32API)가 mkxp-z/Joiplay에서 실제 동작하는지 실기 확인이
  선행(P-1). 안 되면 토글 키 입력을 엔진 Input으로 갈아야 한다.
- 인게임에서 아무나 `$DEBUG`를 켜는 기능을 정식 배포에 넣을지, 별도 선택 모드로
  둘지 유지자 판정.
