# Z-40 — 잡담 게이트 확장: 애매 층 트리아지와 말투 2차

잡담 분류 3층 게이트([채점판](../log/research/2026-08-09-scene-scorer.md))의 애매 층
— scene 판정은 잡담인데 엄격 필터를 탈락한 이벤트-페이지 약 1,830개 — 을
`deepseek/deepseek-v4-flash`(OpenRouter, 채점 94.3%)로 배치 분류해 확실 층을 넓히고,
넓어진 풀에서 말투 선제 교정 2차 후보를 뽑는다.

## 할 일

1. 트리아지 실행 — 채점판 하네스(`cheap_judge.py` 계열)를 애매 층 전량에. 모델의
   「스토리」 라벨은 통과로 재해석(유지자 정의: 스토리=메인스토리 이벤트). 비용 1달러 미만 추정.
2. 「잡담」 판정분을 확실 층에 편입하고, 급 교정 이력 스프라이트의 미수정 문안을
   다시 추출(1차와 같은 절차 — 방향 근거에서 선택지·상속 오귀속 제외).
3. 후보 시트는 이벤트-페이지 전문으로 유지자 판정 → 승인분 재작성은 메인 세션이
   직접(번역 문안에 서브 금지 — 세션 메모리 규칙).
4. 보류 재료: revolucionario(진행도 의존 말투 — 흉흉한 시기만 딱딱한 반말),
   mosqueterow 카페 교환 이웃 줄(합쇼 잔존, 개별 설정으로 내릴지).

## 근거

- 1차 결산: 4방향 43줄 반영(커밋 `2196456`), 기각 8방향의 추출 결함 셋
  ([후보 시트](../log/research/2026-08-09-register-candidates.md) 판정 기록).
- 저가 모델 채점: flash 94.3% > luna 92.0%, 두 모델 맹점 동일해 이중화 무익
  (채점판 문서 「저가 모델 시험」·「유지자 정의 교정」 절).
