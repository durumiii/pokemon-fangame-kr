# Z-70 — 본가 자구와 어긋나는 76행 판정

**단계** P-2(손댈 자리부터 가른다) · **크기** 중간

원문이 본가 문장 코퍼스와 **완전히 같은** 줄만 골라 한국어를 견줬더니 76행이 갈렸다.
절03 도감 설명 9 · 절06 기술 설명 40 · 절09 도구 설명 26 · 절11 특성 설명 1.
전량은 [어긋남 목록](../log/research/2026-08-17-corpus-divergence.jsonl)(76줄, 절·번호·현행·
본가·원문). 발견 경위는 [커버리지 조사](../log/research/2026-08-17-verify-coverage.md).

전거 서열상 **본가에 있는 자구는 판정하지 않고 조회한다**(glossary 머리). 그러니 원칙으로는
전부 본가 쪽인데, 의도적 의역이 섞여 있을 수 있어 **먼저 갈라야 한다.** 표본:

- 절06 i=53 — 현행 「2~3턴」 대 본가 「2-3턴」(부호만 다르다)
- 절09 i=37 — 현행 「평범한 깃털」 대 본가 「평범한 날개」
- 절03 i=453 — 현행 「맹독이 밴」 대 본가 「맹독이 배인」

## 할 일

1. 76행을 셋으로 가른다 — 본가 자구로 갈 것 · 의도적 의역이라 둘 것 · 판정이 필요한 것.
   부호·띄어쓰기 차이는 기계로 가려 앞쪽에 몰아 넣는다.
2. 갈린 결과를 유지자에게 재료(원문·현행·본가·자리)를 갖춰 올린다.
3. 반영 뒤 이 대조를 [Z-69](Z-69.md)의 검사에 얹을지 정한다 — 예외 목록이 서면 게이트가 되고,
   안 서면 조회 전용으로 둔다.
