# Z-52 — 유틸 모드 통합 경계 정하기 (뒤로 미룸)

보관소 모드가 열일곱이고 그중 유틸 성격이 열하나다. 설치도 충돌 관리도 무거워졌다.

## 지금 상태

| 갈래 | 모드 |
|---|---|
| 번역에 묶임 | 한글패치 코어 · UI Text KR · 글꼴 셋(DPPt·갈무리·BW) · Z-GUI |
| 조작·입력 | Controller UX · Better Movements |
| 전투 | Battle Order · Battle Speed · Battle Scene Speed · Type Matchup |
| 성능·호환 | Native Tilemap · GC Tamer · Frame Profiler |
| 개발용 | 디버그(Z-48에서 하나로) |

## 물을 것

- 전투 속도 둘(`Battle Speed`·`Battle Scene Speed`)은 이름도 기능도 인접해 지금도
  헷갈린다. Z-50이 가져올 체력 게이지가 정확히 그 사이에 떨어진다.
- 묶는 단위는 「켜고 끄는 이유」로 가른다 — 번역에 묶인 것과 취향인 것은 생명주기가 다르다.
- `Frame Profiler`는 개발용에 가깝다.

Z-48·49·50이 끝난 뒤 실제 모양을 보고 정한다.
