# Z-53 ② 설계 — 00-maps 안쪽 구조화

**2026-08-18 유지자 승인.** 티켓 [Z-53](Z-53.md) 「남은 일」 ②의 설계 정본.
그림은 [Z-53-structmap.d2](Z-53-structmap.d2).
이해 정렬(2026-08-18)에서 확정된 전제 — **목적은 규칙 구분의 단일화와 정본 자체의
가독·편집성이고, 주 독자는 에이전트다**(사람은 스튜디오로 본다). 휴리스틱 값은 정본
칸에 앉히되 유래를 싣고, 판정으로 덮을 때는 overrides가 이긴다.

## 1. 푸는 문제 (실측 2026-08-18)

**같은 구분을 도구마다 다른 칸 조합으로 재계산한다.**

| 도구 | 묻는 것 | 쓰는 칸 조합 | 자리 |
|---|---|---|---|
| `register.py` | 급 검사 대상인가 | kind+how+who — **층은 안 본다** | register.py:226 |
| `batch_pages.py` npc 갈래 | 잡담 배치 대상인가 | kind+how=그림+personas 등재 | batch_pages.py:508 |
| `batch_pages.py` 주연 판정 | 장면인가 잡담인가 | **scene 칸을 쓰는 유일한 한 줄** | batch_pages.py:485 |
| `speaker.py classify` | 층(PS/PC/N) | cast+sprite+how | speaker.py:668 |

한 군데가 규칙을 바꿔도 나머지는 안 바뀐다. 유지자가 예시로 든 「주역들 여럿이
대화하는 씬 vs NPC 잡담」의 갈림이 batch_pages의 한 줄에만 산다.

- **sites의 layer·kind·scene·how는 귀속표 추론값의 무가공 사본이다**(gen.py:27
  ATTR_FIELDS — 값 존재만 걸러 그대로 복사). 판정 지위도 유래 표시도 없다.
- **지문 층(N 4,145행) 내부를 가를 칸이 없다.** how 분포는 미상 1,666 · 선택지 1,121 ·
  지문 1,112 · 그림 155 · 태그 73 — 안내판·편지·일기·시스템 알림이 미상에 뒤섞여
  있고 sprite 칸 자체가 sites에 없다(8-14 미결 목표가 그대로 남은 자리).
- **axes.yaml의 kind 선언(say/narration/choice/system/ui)은 죽은 선언이다.** sites
  실물은 text/choice/battle이고, 선언 enum을 검사·소비하는 코드가 0이다.
- **flat이라 장면 단위 읽기가 전부 수제 조인이다.** 에이전트가 이벤트 하나를 보려면
  id 접두 파싱 + sites·messages 조인을 제 셈으로 한다.

규모(실측): 맵 절 19,823행 = 맵 475 · 이벤트 3,663 · 페이지 4,700. 페이지당 평균
4.2행·최대 91행. 화자 2인 이상 페이지 189 · 1인 3,634 · 무화자 877.

## 2. 모양 — 페이지 레코드 층 하나를 세운다

sites/messages의 줄 꼴은 그대로 두고(중첩 재편 안 함), **일곱째 파일 `pages.jsonl`**을
세운다. 한 줄 = 한 (맵, 이벤트, 페이지), 4,700행. 기계 생성(gen) + overrides.

```jsonl
{"id":"m3.e2.p0","layer":"PS","scene":"컷신","by":"machine/gen"}
{"id":"m26.e4.p0","layer":"PC","scene":"잡담","by":"machine/gen"}
{"id":"m213.e4.p0","layer":"PS","scene":"컷신","by":"human/2026-08-18","why":"장면 끝 내레이션 — 행 c88은 who 비움"}
```

**행 사실은 행에, 페이지 판정은 페이지에.** 「말투가 100% 정확도로 참조될 수 있는
연결은 개별 행→말투뿐이고 이벤트 룰은 휴리스틱」(유지자, 8-14) — 이 지위 차이를
파일 경계로 새긴다. who·how·kind·src는 행 사실이라 sites에 남고, layer·scene은
페이지 단위 판정이라 pages로 올라간다. `by`가 유래(machine/human)를 나른다.

- **이행이 끝나면 sites에서 layer·scene 사본 칸을 걷는다.** 19,823행의 중복 사본이
  4,700행 한 벌이 된다. 두 칸은 emit이 ko로 안 내리므로 diff 0과 무관하다.
- **overrides 창구는 그대로 쓴다** — pages id를 받도록 gate 검사 0의 id 실재 검사만
  넓힌다. 층·장면 오판정의 사람 교정이 지금과 같은 한 줄 꼴로 남는다.

### 공용 구분 로더 — 재계산 걷기의 본체

`stage0/`에 로더 한 벌을 두고(이름 후보 `structure.py`), 도구들이 「이 행의
층은 · 이 페이지는 장면인가 잡담인가 · 이 행의 말투는 어느 표로 가나」를 전부
그것으로 묻는다. 값 수정이 `edit.py put_lines` 하나로 모인 것과 같은 꼴이다.

- 화자→말투 연결(이름표면 voices, 그림이면 groups)은 **칸이 아니라 이 로더의 규칙
  하나**로 앉는다(`voice_ref`) — 지금 how 값(태그/상속 vs 그림)에서 유도되는 규칙이
  도구마다 복제돼 있는 것을 한 곳으로.
- **행에 적힌 층이 먼저, 없으면 페이지 판정**(`row_layer`, 2026-08-18 이행에서 조정) —
  overrides에 든 행 단위 사람 판정 8건(컷신 안 확인창·회상 자막을 행 하나씩 N으로)이
  페이지 다수결에 지워지지 않게 하는 경계다. 3단계에서 sites의 layer 사본 칸이
  걷히면 저절로 페이지 판정으로 내려앉고 overrides 행만 예외로 남는다.
- 전환은 강등 선례의 두 걸음 — 도구마다 로더 경유 산출과 현행 산출의 동치를 증명한
  뒤 자체 재계산을 걷는다. 대상: register.py · batch_pages.py(갈래 셋) ·
  materials.py · scene_eval.py.

### 장면 단위 읽기

에이전트의 장면 읽기(id 접두 grep + 수제 조인)는 로더의 조회 함수로 흡수한다 —
materials.py가 이미 하는 일의 공용화라 새 발명이 아니다. 정본 파일 자체를 중첩으로
바꾸는 안은 기각: gen·emit·diff·edit·gate 전부가 움직여야 하고, 얻는 것은 로더
한 벌이 같은 값에 더 싸게 준다.

## 3. 지문 층 내부 갈래 — 자리만 판다

행 단위 칸 하나(이름 후보 `nkind`, 값 등재제: 안내판 · 편지 · 일기 · 시스템 ·
연출지문 · 미상)를 sites 스키마에 등재하되, **값 채움은 이번 범위 밖이다.** 기존
신호가 없음이 실측됐으므로 새 휴리스틱이 필요하고, 휴리스틱은 정답 표본 채점을
먼저 통과해야 쓴다(전역 규율). P-1(표본 라벨) → 채점 → 채움 순서의 별도 걸음.

## 4. 축 등재 정리

- **kind 선언을 실물값(text/choice/battle)으로 고친다.** say/narration/… 다섯 값은
  어느 코드도 안 쓰는 설계 시점의 이상값이었다.
- **gate에 enum 검사를 추가한다** — axes.yaml의 `values`가 선언된 축(kind·mart,
  pages의 scene·layer도 등재)에 대해 정본 실물값이 등재 밖이면 FAIL. 「조용히 안
  깨지고 시끄럽게」가 지금은 선언만 있고 검사가 없다.
- **layout 블록은 axes.yaml에서 갈라 `layout.yaml`로 낸다.** 축이 아니라 그릇의
  뼈대이고(gen 주석 그대로), 소비자는 diff.py:67 하나뿐이라 이동이 싸다. axes에는
  등재제 축과 우선순위만 남는다.

## 5. 미결 둘의 해소

- **loc 정본 흡수 — 이미 돼 있다(실측).** sites의 `apply=krloc` 54자리와 messages의
  val·why가 정본이고, `translate/ko/00-maps.loc.jsonl`은 diff.py:87-97이 「왜」까지
  왕복 역생성하는 산출물이다. 설계 판정은 선언뿐 — text-pipeline에 「loc도 ko와
  같은 격의 산출물」 한 줄을 얹고, loc 값을 갈 때 줄기 B에 알리는 예의만 남는다.
- **layout 거취 — 위 4절.** 3단계 정리 때로 미뤄 둔 것을 이번에 함께 정리한다.

## 6. 안 하는 것

- **처방 등급(기능 창구 357페이지) 등재** — 정본 밖 `data/scene/counter-pages.jsonl`에
  있고, 등급 3의 실무 절반은 unified 참조가 이미 담는다. 등재 여부·자리는 별도
  논의(유지자). pages 층이 서면 앉을 그릇은 생긴다.
- **지문 갈래 값 채움** — 3절, 채점 뒤.
- **sites/messages 중첩 재편** — 페이지 층 + 로더로 부족함이 실증되면 재론.
- **씬 축 정교화** — 「가를 수 있으나 처방을 안 바꾼다」(8-14 판정) 그대로.
