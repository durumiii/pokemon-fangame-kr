# Z-41 — 배틀 처리 순서를 본가 기준으로 (모드 `Battle Order`)

유지자 제보 셋에서 출발해 배틀 순서를 전수 감사하고, 결함 넷을 모드 하나로 고친다.
조사와 근거는 [감사 기록](../log/research/2026-08-10-battle-order-audit.md),
판정은 [품질 원장](../ledger/quality.md)의 「배틀 처리 순서는 최신 세대를 따른다」 절,
무엇을 어디서 떠 와 어디를 바꿨는지는
[모드 README](../../mods/Battle%20Order/README.md)가 정본이다.

기준은 **최신 세대**다(유지자 판정 2026-08-10). 8세대에 들어온 「행동마다 순서 재계산」을
채택한다.

## 고치는 것 넷

- **행동 순서가 턴 시작에 고정된다** — 턴 도중 걸린 마비, 교체로 들어온 포켓몬의 등장
  특성이 깐 트릭룸·날씨가 그 턴에 반영되지 않는다. 제보 ②(파라섹트 트릭룸)와
  ③(마비가 안 먹는 것처럼 보임)이 같은 뿌리다.
- **라운드 종료가 「체력 먼저, 연출·메시지 나중」** — 독·화상·얼음·모래바람·저주·악몽·
  조이기·끈적끈적바늘·태양의힘 열한 자리.
- **먹밥·검은먹밥도 메시지가 체력 뒤** — 세 자리.
- **선제의발톱 메시지가 턴 머리에 몰려 나온다** — 표시만 실제 행동 직전으로 옮긴다.
  판정 시점은 그대로라 실제 순서는 안 달라진다.

## 손대지 않기로 한 것 (유지자 판정 2026-08-10)

마비의 스피드 감소 배율(이 게임 ¼, 7세대 이후 본가 ½) · 날씨 연동 회복 특성의 위치 ·
싸라기눈 데미지가 꺼져 있는 것. 앞의 것은 밸런스 변경이라 지금 자리가 아니고, 뒤의 둘은
영향이 없거나 최신 기준으로 오히려 맞다.
