# Z-34 — Essentials 번역층 경로 조사 + reuse-playbook 등재

절23의 UI 문구 대부분이 Pokémon Essentials 개발킷 보일러플레이트(스페인어 커뮤니티
번역층)라는 것이 Z-3에서 실측으로 드러났다 — 이 게임에 없는 화면의 죽은 키(Oak·
Lullaby·NOT ENTERED), 개발툴 문구(애니메이션·트레이너 편집기) 등. 그렇다면 다음
팬게임에서는 스크립트를 뜯기 전에 개발킷 번역층을 키 단위로 기계 치환하는 부트스트랩
경로가 성립한다 (유지자 발안, 2026-08-09).

## 할 일

1. **판본 판별** — 이 게임이 쓴 Essentials 판본과 스페인어 번역 패키지를 스크립트
   실물에서 확정한다 (버전 상수·크레딧·번역층 특징).
2. **한국어 번역층 존재 확인** — 그 판(또는 인접 판)의 한국어 Essentials 커뮤니티
   번역이 존재하는지, 키 집합이 절23과 얼마나 겹치는지 잰다.
3. **reuse-playbook 등재** — 성립하면 부트스트랩 순서를 가이드에 올린다:
   판본 판별 → 번역층 대조표 확보 → UI 절 기계 치환 → 본가 자구 정렬(canon_sweep).

## 유의

- 이 게임(pokemon-z)에 소급 적용할 실익은 낮다 — 절23은 이미 번역·본가 정렬이
  끝났다. 산출물의 수혜자는 다음 게임이다.
- 한국어 번역층은 커뮤니티 산물이라 본가 자구가 아니다 — 부트스트랩이지 정렬
  대체가 아니라는 것을 playbook에 함께 적는다.
