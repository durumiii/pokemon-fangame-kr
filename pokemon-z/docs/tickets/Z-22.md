# Z-22 — `fixgui.py`를 로컬 스튜디오로

유지자 판단 2026-08-08. 웹 스튜디오(`webapp/`)의 기능을 로컬 `translate/fixgui.py`로
옮겨 와, 유지자는 **정본을 직접 수정·빌드**한다(회수 절차 불요). 웹 스튜디오는
유저용으로 남긴다.

## 옮길 것 / 남길 것 (2026-08-09 확정)

이식 방식은 **필요한 것만 새로 쓰기**로 정했다(유지자 판단 2026-08-09). 웹의 화면
코드는 dat + pyodide + localStorage 전제 위에 서 있어 정본 jsonl 모델과 안 맞는다 —
규칙만 베끼고 코드는 fixgui 방식으로 짧게 다시 쓴다.

- ✅ 일괄 바꾸기 세 갈래(번역 기준 / 원문 조건 / 원문 기준) + 미리보기·선택 적용,
  동작 묶음 이력과 묶음째 되돌리기. 화면 규약은
  [text-pipeline](../guides/text-pipeline.md) 「로컬 스튜디오」 절이 정본.
- 남은 것 — 검색 결과 카드의 **이벤트 칩**(그 대사가 속한 이벤트-페이지를 명령
  순서대로). 웹은 `webapp/speakers.json`의 `rows[원문][2]`를 쓰고, 그 파일은
  `translate/make_speakers.py`가 만든다.
- 웹에 남길 것 — 제보 송신(구글폼) · dat 직접 수정 경로. 로컬판은 정본(jsonl)을 고치고
  `build.py`로 내려보내므로 dat를 만질 이유가 없다.
- 착수 전에 [webapp/AGENTS.md](../../webapp/AGENTS.md)(파일 역할표·수정 금지 목록)를 읽는다.

## 왜

웹 스튜디오는 dat를 고치므로 `harvest.py` 회수가 한 단계 더 필요하고, 회수를
`export.py`로 잘못 하면 정본이 되돌아가는 함정이 있다(2026-08-08 실측 282행).
유지자의 수정이 정본에 바로 앉으면 그 단계가 통째로 사라진다.
