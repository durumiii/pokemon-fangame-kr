# Z-4 — 이름표 없는 NPC 대사 정비 (재정의 2026-08-09)

원래 「6,985행 전량 재번역」이었으나 [표본 감사](../log/research/2026-08-09-z4-sample-audit.md)로
재정의했다 — 잡담 층 행 단위 품질은 준수(표본 결함 12%)하고 문제는 말투 배정에
몰려 있어, 재번역 대신 아래 세 갈래로 간다.

## 할 일

1. **잡담 3,925행 급 통일 배치** — 존대·반말 정면 혼재 스프라이트 48종(판정 가능
   104종 중)의 말투를 정하고, 내용 고정·어미와 격만 맞추는 처방 2등급 배치.
   말투 배정은 [events-and-speech](../guides/events-and-speech.md)의 잡담 층 정리
   기준, 페르소나는 `translate/persona-table.jsonl`. 풀을 쓸 때 기계 제외
   (숫자·trchar·rayos·objeto 스프라이트) 필터를 반드시 얹는다 — 전수 특징표의
   strict 판정에는 이 제외가 안 들어 있다(표본에서 5/80 누수 실측).
2. **결함 패턴 스윕** — 「당신」 번역투 · 원문에 없는 문두 감탄사 · 울음소리 로마자
   음차(한국어 종명 기반으로 재생성, Naturalness rules P). 전수 grep으로 후보를 뽑아
   유지자 시트로.
3. **컷신·대화 1,540행은 Z-28 선행 후** — 결함의 절반이 「같은 원문 딴 판」(너즐록
   실패 문구 세 판 등)이라 중복 통일이 먼저다. 통일 뒤에 화자 판정을 붙여 재번역.

기존 재료는 그대로 쓴다: `batch_npc.py`, 페르소나표, 잡담 게이트 라벨
([트리아지 결산](../log/research/2026-08-09-ambiguous-triage.md) — 통과 192는 확실
층보다 정밀도가 낮으니 선별 신호로만).
