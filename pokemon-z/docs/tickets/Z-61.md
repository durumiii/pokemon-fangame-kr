# Z-61 — 전이 뒤 대사 67행이 원문으로 뜬다

**단계** P-2(가능성 확인) · **크기** 중간

이벤트가 플레이어를 다른 맵으로 옮긴 뒤 띄우는 대사는 **도착 맵 id로 조회**되는데
정본은 출발 맵에만 등재돼 있어, 번역이 있는데도 화면에 스페인어가 뜬다. 원인·규모·
증거는 [2026-08-16 조사](../log/research/2026-08-16-transfer-then-text.md).

후보 67행 · 이벤트 페이지 31개. 유지자 제보 셋이 여기 속한다.

## 할 일

1. **막힌 자리 확인** — dat의 맵 절(절0)에 새 (키, 값) 쌍을 꼬리에 붙이고 게임이 그것을
   읽는지 최소 한 자리로 확인한다. 해시 절 추가분(`*.add.jsonl`)이 이미 그 방식이라
   같은 조작이 맵 절에도 서는지가 물음이다.
2. 서면 `build.py`의 맵 절 처리에 추가분 경로를 넣는다(줄 수·키 대조가 꼬리를
   허용하도록. 해시 절이 `tail_ok`로 이미 하는 일과 같은 꼴).
3. 후보 67행을 자리마다 열어 **조건 분기 때문에 실제로는 안 걸리는 자리**를 걸러낸다.
   조사의 67은 상한이다.
4. 공통 이벤트(`CommonEvents.rxdata`) 대사가 어느 맵 열쇠로 조회되는지 확인한다 —
   조사에서 안 훑은 층이다.

## 안 하는 것

이벤트를 고쳐 대사를 전이 앞으로 옮기는 길은 원작 데이터 수술이고 연출 순서가 바뀐다.
1·2번이 막힐 때만 유지자 판정으로 다시 꺼낸다.
