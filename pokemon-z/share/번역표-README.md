# 포켓몬 Z 한글패치 — 번역 내역과 도구 안내

읽어주세요.txt에는 설치와 판본 안내만 담았습니다. 무엇을 어떻게 옮겼는지,
번역을 직접 고치려면 어떻게 하는지는 여기에 있습니다.

## 번역을 직접 고치기

이 폴더의 `*.jsonl`이 원문-번역 대응표 전체입니다. 문장을 고치고
`빌드.py`를 한 번 돌리면(파이썬 3 필요) korean.dat가 다시 구워져 자기만의
판이 됩니다. 절차와 주의점은 `번역 도구/수정법.txt`에 있습니다.

## 번역 도구 폴더에 든 것

- `glossary.md` — 용어 규칙·전거 서열·고정 용어표. 번역 판정의 정본.
- `voices.md` — 주연 인물 말투표(42인)와 화법 공통 규칙.
- `persona-table.jsonl` — 일회용 NPC 스프라이트 64종의 페르소나(그림 실측).
- `sprite-groups.json` — 스프라이트 어간 207종의 화자 그룹·어투 버킷 배정.
- `canon.jsonl` — 본가 정식명 대조표(스페인어·영어·한국어 4,824항목, PKHeX 산).
- `exceptions.jsonl` — 본가와 이름만 같은 별개 대상(오적용 방지 목록).
- `messages.jsonl.gz` — 본가 공식 9작(XY~Z-A) 스페인어↔한국어 문장 코퍼스
  163,106쌍(출처 게임·텍스트 파일 라벨 포함). **참고 전용** — 이 게임의
  문장에 기계적으로 옮겨 붙이면 안 됩니다.
- `prompt.md` / `prompt-npc.md` — 재번역 배치에 쓴 프롬프트(재현용).
- `speaker-aliases.json`, `빌드.py`, `rubywrite.py`, `수정법.txt`.

● v5에서 달라진 것

  NPC 말씨 전면 재작성
  · 마을 사람·상점 주인·병사 같은 일회용 NPC 대사 5천여 행을,
    맵 파일에서 화자(외형·역할)를 읽어내 그 사람에 맞는 말씨로
    다시 썼습니다. 실제 포켓몬 정식 한국어판(블랙2 등)의 화법을
    통계로 조사해 기준으로 삼았습니다 — 행인은 반말, 접객은
    해요체, 노인은 하게체, 안내문·지문은 평서체.
  · 주연 인물의 무기명 대사(연출 장면 등)에도 말투표를 적용해
    같은 인물이 어디서나 같은 말투로 말합니다.
  · 재작성 전량을 원문과 다시 대조하는 검수를 한 번 더 돌려
    뜻이 어긋난 자리를 바로잡았습니다.

  지명 정식화 · 그 밖의 수정
  · 도시 13곳의 이름이 본가 XY 칼로스 도시의 스페인어 정식명
    그대로임을 확인하고, 본가 정식 한국어명으로 전환했습니다
    (미르시티·사라시티·이설시티 등, 파생 지명·시설 포함 500여 곳).
  · 포켓몬 성격 이름을 본가 정식 표기로, 드레인 계열 문구를
    정식 문구로, 트릭룸 발동문의 스페인어 잔재를 정리했습니다.
  · 연금술 화면 하단 안내, 저장 불러오기 라벨 등 코드에 박힌
    문자열을 추가로 한글화했습니다.
  · 부적 계열 도구 18종이 번역 후 작동하지 않던 기능 결함을
    찾아 고쳤습니다(이름 비교 → 내부 상수 비교).


● 설치

  1) 게임 폴더를 통째로 백업합니다.
  2) 이 폴더의 내용물을 게임 폴더에 그대로 덮어씁니다.
     (Data, Fonts, Graphics, Audio 폴더와 mkxp.json)
  3) 게임을 켜면 한국어로 시작합니다.

  타이틀의 Idioma 메뉴에서 언제든 스페인어 원문으로 되돌릴 수
  있습니다. 원문 데이터는 건드리지 않습니다.

  꼭 지킬 것 셋 —
  · mkxp.json이 빠지면 한글이 전부 네모(□)로 나옵니다.
  · Data 폴더는 통째로 덮어써야 합니다. Scripts.rxdata가 빠지면
    스페인어로 뜨고 조사 자동 선택도 빠집니다.
  · 게임 옵션의 vsync는 꺼 주세요.(켜면 이름 입력에서 키보드가
    먹히지 않습니다.)

  참고: 번역표 폴더는 게임 동작과 무관합니다. 번역을 직접 고치고
  싶을 때만 쓰는 재료라, 복사하지 않아도 됩니다.


● 무엇을 어떻게 했나

  본문 전량 재번역
  · 이미 번역돼 있던 문장 1만 4천여 개를 스페인어 원문과 나란히
    놓고 전부 다시 다듬었습니다. 다섯 단계를 거쳤습니다.
  · 기계 초벌 — 맵(장면) 단위로 묶어 문맥을 유지한 채 문장을 다시
    썼습니다. 프롬프트에 용어집과 그 장면 화자의 말투표를 실어,
    같은 인물은 어디서나 같은 말투로 말하게 했습니다.
  · 자동 검사 — 색·이름·숫자가 들어가는 제어 코드, 문장 길이,
    줄 수를 기계로 검사해 하나라도 어긋나면 그 문장을 반려하고
    원래 번역을 유지했습니다.
  · 교차 발굴 — 다른 계열의 모델 셋이 원문 대조로 의심 문장
    약 3,700곳을 찾았습니다. 뜻이 바뀐 곳, 원문에 없는 수식,
    단수·복수 어긋남, 비문이 표적입니다.
  · 판정 — 발굴된 후보를 상위 모델이 하나씩 원문과 대조해 진짜
    결함으로 확인된 850여 곳을 고쳤습니다. 주어가 뒤바뀐 문장
    ("네가 포켓몬을 아낀다" → 원문은 "포켓몬이 너를 좋아한다"),
    수량 왜곡("한 꼬집"이 "한 스푼"으로), 존칭 비문("왕시여")
    같은 것들입니다.
  · 재조립 — 고친 번역을 다시 굽고, 고유명사가 흔들린 자리를
    용어표 기준으로 한 번 더 쓸어냈습니다.

  미번역 문구 번역
  · 스페인어로 남아 있던 시스템 문구 3,100여 행을 게임 코드와
    대조해, 실제로 화면에 나올 수 있는 1,300여 행만 새로
    번역했습니다. 나머지는 이 게임이 부르지 않는 죽은 문자열이거나
    개발자 전용 화면입니다.
  · 열매 수확, 괴력·파도타기 안내, 기술 잊기 확인, 성격·능력치
    이름, 가방 주머니 이름 등의 미번역 문구를 새로 옮겼습니다.
  · 키가 어긋나 화면에 나오지 못하던 문구들(아이템을 주울 때의 안내, 
    상대 트레이너의 포켓몬 교체문구 등)도 원인을 찾아 살렸습니다.

  본가 표현 정합
  · 전투 문구는 한국 정식 발매판의 전통 표현을 그대로 씁니다 —
    "효과가 굉장했다!", "급소에 맞았다!", "OO은(는) 쓰러졌다!" 류.
    정식 3세대 한국어판 텍스트와 정식판 계열 번역 자료를 전거로
    한 문장씩 맞췄습니다.
  · 상태이상·날씨·설치 기술·랭크 변화·포획·경험치 문구, 씨뿌리기
    같은 기술 고유 문구까지 같은 기준으로 통일했습니다.
  · 전투 밖에서도 리포트 저장, 진화("어라...? OO의 모습이...!"),
    상점·PC·닉네임·낚시 문구를 본가식으로 맞췄습니다.
  · 도감은 한 걸음 더 가서, 본가 포켓몬의 분류와 설명이 정식
    한국어판 문안과 같은 판본이면 공식 문안을 그대로 실었습니다.
    한국어판이 존재하지 않는 판본(3세대 에메랄드 계열)만 검수를
    거친 팬번역으로 채웠습니다.

  인물명·용어 번역
  · 이전 판 한글패치는 인물명을 스페인어 원문대로 두었는데
    (Crisanto, Melia ...), 이 판은 인물 361명을 스페인어·프랑스어
    발음 기준으로 음차했습니다(크리산토, 멜리아, 올리비에 ...).
  · 본가와 겹치는 이름은 하나씩 판정했습니다. 예를 들어 Clem은
    본가 XY 시트론의 여동생(한국명 유리카)의 프랑스 이름과 같지만,
    이 게임의 Clem은 그 인물이 아니라 오마주로 만든 별개 인물로
    판정해 「클렘」으로 음차했습니다. 반대로 Kanto처럼 본가 지명이
    그대로 나오는 자리는 정식 명칭 「관동」을 씁니다.
  · 포켓몬 종·기술·도구·특성 이름은 공식 대응표(스페인어·영어·
    한국어 3개 언어 사전 311항목을 하나씩 검증해 만든 것)로 전수
    대조했고, 같은 낱말이 여러 표기로 흔들리던 자리(화폐 단위,
    연금술, 배틀/시합 등)를 한 표기로 통일했습니다.
  · 한 가지 밝혀 둘 선택이 있습니다. 본가와 같은 인물·지명·용어가
    그대로 등장하면 이 패치는 본가 정식 한국어명을 따릅니다.
    스페인어/프랑스어 음차 쪽이 이 게임의 왕정 시대극 어감에는 더
    어울린다고 볼 수도 있어서 논쟁적일 수 있는 선택입니다 — 우리는
    본가와 이어 읽히는 쪽을 골랐습니다. 음차를 원하시면 번역표에서
    직접 바꿔 자기 판을 만들 수 있습니다.

  UI 텍스트 수정(추가 플러그인)
  · 번역 데이터가 아니라 게임 코드 안에 박혀 있어 기존 방식으로는
    못 고치는 문자열들을 스크립트로 바꿨습니다.
  · 일시정지 메뉴의 단축키 라벨, 야생 포켓몬 안내판, 배지 이름,
    그리고 저장 불러오기 화면의 지명(번역 데이터를 안 거치고 영문
    내부 이름이 그대로 뜨던 자리)이 여기 해당합니다.

  조사 자동 선택(추가 플러그인)
  · 은/는·이/가·을/를이 앞 낱말의 받침에 맞게 자동으로 붙는
    스크립트를 넣었습니다. 포켓몬 이름이 어디에 들어가든 조사가
    어긋나지 않습니다.
  · 숫자·알파벳으로 끝나는 낱말의 읽기 판정, (으)로의 ㄹ 받침
    특례도 포함합니다.
